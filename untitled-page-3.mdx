# Documentation Updates

<Info>
  ## Major Update

  [**Cross-Training & Queue Scope**](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/Informational-Basic-Service-Ops-Guidelines-and-Rules#cross-training-and-queue-scope) — _(Informational: Basic Service Ops Guidelines and Rules)_

  **Why it matters:**

  - Queue-scope rules for cross-trained/Flex associates were never formally documented until now.

  **What changed;**

  - No documented rule → Formal queue-scope reference for single-queue, Flex (SMS + TS), and Flex (CC + TS) assignments, with handoff steps for each.

  **What you need to do:**

  - Work only within your assigned queue(s). If Flex, create the TS task before picking it up yourself. If Flex (CC + TS), ask diagnostic questions only on the inbound call — troubleshoot via a new outbound call from the WO.

  **When it takes effect:**

  - Monday, 09/07

  **Resources impacted:**

  - [Informational: Basic Service Ops Guidelines and Rules](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/Informational-Basic-Service-Ops-Guidelines-and-Rules) (new "Cross-Training & Queue Scope" section)

  ## Minor Updates

  - **[Job Aid: What is a task?](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/Job-Aid-What-is-a-task#task-fields) & [(Operations Associate) Job-Aid: Latchel Service Ops Assistant Plug-in](https://help.latchel.com/latchel-admin/Service-Operations/Operations-Associate-Job-Aid-Latchel-Service-Ops-Assistant-Plug-in#if-your-queue-looks-empty')**
