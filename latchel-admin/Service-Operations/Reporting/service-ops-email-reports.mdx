**1.** This Freshdesk dashboard shows volume metrics for the Freshdesk tickets.

**2.** This Freshdesk dashboard shows performance metrics for the Freshdesk tickets, such as average first response time.

**3.** This report provides real-time information on the number of open admin emails and the duration since their creation. Additionally, it includes a tally of resolved administrator emails. Furthermore, you can view the agents' names and details about the latest email they sent via Freshdesk.
