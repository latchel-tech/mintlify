<Info>
  **Purpose**: This Job Aid serves as a comprehensive list of all available email reports that the Service Operations Team can use for reference, analysis, and managing daily functions.
</Info>

### **Email Reports**

1. **Helpdesk Ticket Volume**

|  | **Helpdesk Ticket Volume References** |
| :-- | :-- |
| **Description** | This Freshdesk dashboard shows volume metrics for the Freshdesk tickets. |
| **Dashboard** | Freshdesk |
| **Legacy Report** | Zendesk dashboard (deprecated) |
| **Viewer Notes (Tips / Be Aware)** | You can adjust the filter to see different dates or groups, like “emergency” group for admin tickets or “team” group for non-emergency tickets. By default the report shows non emergency tickets from the last week. |

2. **Helpdesk Performance**

|  | Helpdesk Performance References |
| --- | --- |
| **Description** | This Freshdesk dashboard shows performance metrics for the Freshdesk tickets, such as average first response time. |
| **Dashboard** | Freshdesk |
| **Legacy Report (if applicable)** | Zendesk dashboard (deprecated) |
| **Viewer Notes (Tips / Be Aware)** | You can adjust the filter to see different dates or groups, like “emergency” group for admin tickets or “team” group for non-emergency tickets. By default the report shows non emergency tickets from the last week. |

3. **Admin Emails**

|  | **Admin Emails References** |
| --- | --- |
| **Description** | This report provides real-time information on the number of open admin emails and the duration since their creation. Additionally, it includes a tally of resolved administrator emails. Furthermore, you can view the agents' names and details about the latest email they sent via Freshdesk. |
| **Dashboard** | Emergencies Real time Dashboard 2.0 |
| **Folder** | Real Time |
| **Legacy Report (if applicable)** | Emergency Real Time Monitoring |
| **Viewer Notes (Tips / Be Aware)** | You can adjust the filter to see different date ranges |
