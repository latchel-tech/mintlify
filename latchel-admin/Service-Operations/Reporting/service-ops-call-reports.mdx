3. [CC Vol Histogram](https://lookerstudio.google.com/u/0/reporting/08a7c003-8b2a-4063-9527-5bb7f61cfc72/page/p_zkehrx4vxc "https://lookerstudio.google.com/u/0/reporting/08a7c003-8b2a-4063-9527-5bb7f61cfc72/page/p_zkehrx4vxc")

|  | CC Vol Histogram References |
| --- | --- |
| **Description** | This report helps us determine which Call Center won the call.<br /><br />- It joins the Twillio table to understand who won the call using the SID and the Phone Number.<br /><br />This query uses our call\_dueling table and filters out only those with status won (this filtering is done in the report, not in the query). | **Folder** | Histograms |
| **Dashboard Type** | Call Center Roll Over |
| **Query Used** | `SELECT d.call_sid, d.created_at, d.outbound_phone, d.status, c.duration, c.price, c.direction FROM data-analytics-warehouse.duelling_real_time_public.duelling_call_center_call d LEFT JOIN data-analytics-warehouse.twilio.call c ON d.call_sid=c.id WHERE DATETIME(cast(d.created_at as timestamp), 'America/Los_Angeles') BETWEEN PARSE_DATE('%Y%m%d',@DS_START_DATE) AND PARSE_DATE('%Y%m%d',@DS_END_DATE) ORDER BY created_at DESC` |
