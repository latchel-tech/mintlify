### Report Names

1. **Calls**

<AccordionGroup>
  <Accordion title="Description">
    This Report queries the calls received in ZenDesk

    - Direction Inbound
    - Status: Completed & Handled (cases where there is a hold time, duration, talk time)
  </Accordion>

  <Accordion title="Folder">
    Calls
  </Accordion>

  <Accordion title="Dashboard Type">
    Productivity
  </Accordion>

  <Accordion title="Query Used">
    ```sql lines
    SELECT c.phone_number, datetime(c.created_at,'America/Los_Angeles') as created_at, u.name,  c.duration, c.hold_time,  c.talk_time, c.wrap_up_time , c.completion_status,c.direction
    FROM `data-analytics-warehouse.zendesk.call_metric` c
    LEFT JOIN `data-analytics-warehouse.zendesk.user` u
     on c.agent_id=u.id 
     where u.name is not null
    and direction='inbound' and completion_status='completed'
    ```
  </Accordion>

  <Accordion title="Legacy Report (if applicable)">
    [Team Calls Handled](https://docs.google.com/spreadsheets/d/1GkVMrKOoraOCCafuBIKxQka6kxDYex2-UVrAA1usFkc/edit#gid=1152056671&range=A1 "https://docs.google.com/spreadsheets/d/1GkVMrKOoraOCCafuBIKxQka6kxDYex2-UVrAA1usFkc/edit#gid=1152056671&range=A1")
  </Accordion>

3. **CC Vol Histogram**

<AccordionGroup>
  <Accordion title="Description">
    This report helps us determine which Call Center won the call.

    - It joins the Twillio table to understand who won the call using the SID and the Phone Number.

    This query uses our call\_dueling table and filters out only those with status won (this filtering is done in the report, not in the query). We’ll see a difference in this report versus the productivity call report because this is filtering out calls that are “abandoned throughout the path”.
  </Accordion>

  <Accordion title="Folder">
    Histograms
  </Accordion>

  <Accordion title="Dashboard Type">
    Call Center Roll Over
  </Accordion>

  <Accordion title="Query Used">
    ```sql lines
    SELECT d.call_sid,
    d.created_at,
    d.outbound_phone,
    d.status,
    c.duration,
    c.price ,
    c.direction
    FROM `data-analytics-warehouse.duelling_real_time_public.dueling_call_center_call` d
    LEFT JOIN `data-analytics-warehouse.twilio.call` c
    ON d.call_sid=c.id
    WHERE DATETIME(cast(d.created_at as timestamp), 'America/Los_Angeles') BETWEEN PARSE_DATE('%Y%m%d',@DS_START_DATE) AND PARSE_DATE('%Y%m%d',@DS_END_DATE)
    ORDER BY created_at DESC
    ```
  </Accordion>

  <Accordion title="Legacy Report (if applicable)">
    [Call Center Roll Over 2022](https://docs.google.com/spreadsheets/d/1GkVMrKOoraOCCafuBIKxQka6kxDYex2-UVrAA1usFkc/edit#gid=8455115&range=A64)
  </Accordion>

  <Accordion title="Viewer Notes (Tips / Be Aware)">
    This is the best report to see how many calls reached our database – actual calls handled by either the call center or Latchel. **Recommended call volume report for staffing.**
  </Accordion>
</AccordionGroup>

4. **Calls Heat Map**

<AccordionGroup>
  <Accordion title="Description">
    This report uses the same tables as the one above (calls and call metrics), however, it has a filter to only include completed and inbound calls (excludes outbound calls). This is to understand all calls hitting ZenDesk.
  </Accordion>

  <Accordion title="Folder">
    Miscellaneous Charts
  </Accordion>

  <Accordion title="Dashboard Type">
    Call Center Roll Over
  </Accordion>

  <Accordion title="Query Used">
    ```sql lines
    SELECT c.phone_number, datetime(c.created_at,'America/Los_Angeles') as created_at, c.duration, c.hold_time, c.talk_time, c.wrap_up_time , c.completion_status,c.direction
    FROM `data-analytics-warehouse.zendesk.call_metric` c
    WHERE date(datetime(c.created_at,'America/Los_Angeles') ) between PARSE_DATE('%Y%m%d',@DS_START_DATE) AND PARSE_DATE('%Y%m%d',@DS_END_DATE)
    ```
