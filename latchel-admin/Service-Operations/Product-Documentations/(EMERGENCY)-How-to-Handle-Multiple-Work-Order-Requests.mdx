## 🧠 What This Process Is Trying to Solve


<Note>
We want to prevent confusion, missed emergencies, and double-dispatching when a resident reports multiple issues—especially when both emergency and non-emergency requests are involved. The goal is to ensure each issue is properly categorized, split, and assigned to the right service provider, so every urgent request is addressed quickly, resources aren’t wasted, and customers get clear communication and fast resolution from Latchel.
</Note>


## 📋 Step-by-Step Process


### **<u>1 - The Resident has one or several Non-emergency request(s) AND one or several Emergency request(s)</u>**

**<u>How to Handle Multiple Work Order Requests 1: The Resident has one or several Non-emergency request(s) AND one or several Emergency request(s)</u>**

1. **<u>STEP 1:</u>** Create new work order(s) to address the non-emergency request(s).
  1. If there are multiple Non-Emergency requests, include them all on one work order. See: [(TECH 101) How to: Create a New Work Order from "Incognito Mode" (All Submissions)](https://help.latchel.com/how-to-create-a-new-work-order-from-incognito-mode-all-submissions)
    1. **📝 NOTE:** Non-Emergency Requests are automatically forwarded to the responsible party:
      1. For **24/7 Emergency Subscription** or **After Hours Emergency Subscription or Autopilot Subscriptions,** the Property Manager will be alerted about the Non-Emergency request.
      2. For **Premium, **the request will be forwarded to the Latchel Internal team.

    2. Make an effective Note about other (separate) Work Orders that were created at the same time of this request. Include the Work Order number.
      1. See: [↔ How to: Write Effective Notes](https://help.latchel.com/how-to-write-effective-notes)

    3. Proceed to handle the Emergency work order
      1. See: [(⛑OVERVIEW) How to: Handle Emergency Work Orders](https://help.latchel.com/how-to-handle-emergency-work-orders)


  2. _**Scenario Example**_: _Resident states they have (1) No heat and (2) The refrigerator light is not working  In original work order, the agent writes a note that "refrigerator light" was created as a separate work order, include work order number of the other Work Order ###._

2. **<u>STEP 2:</u>** Create a new work order to address the Emergency maintenance request. See: [(TECH 101) How to: Create a New Work Order from "Incognito Mode" (All Submissions)](https://help.latchel.com/how-to-create-a-new-work-order-from-incognito-mode-all-submissions)
  1. If there are multiple Emergency requests, Refer to the steps outlined in the SOP for how to handle multiple work order requests:  "[(⛑ EMERGENCY) How to: Handle Multiple Work Order Requests](https://help.latchel.com/emergency-how-to-handle-multiple-work-order-requests)"
  2. Proceed to handle the Emergency work order
    1. See: [(⛑OVERVIEW) How to: Handle Emergency Work Orders](https://help.latchel.com/how-to-handle-emergency-work-orders)



- **HELP!** If you are having to split the original work order into three or more work orders, or you are unsure on how to proceed, contact the Operations Support Specialist team.
  - Use the Escalation procedure outlined here: [How to: Escalate Between Teams](https://help.latchel.com/how-to-escalate-between-teams)



### **<u>2 - The Resident has several/multiple Emergency requests</u>**

**<u>How to Handle Multiple Work Order Requests 2:</u> <u>The Resident has several/multiple Emergency requests</u>**

1. **<u>MULTIPLE EMERGENCY WORK ORDERS - OUTCOME 1:</u>**<u> </u>The Emergency requests **require** **different Service Providers** with unique skills assigned for each request.
  1. Create a new Work Order for each Emergency maintenance request.
    1. See: [(TECH 101) How to: Create a New Work Order from "Incognito Mode" (All Submissions)](https://help.latchel.com/how-to-create-a-new-work-order-from-incognito-mode-all-submissions)

  2. Make an effective Note about other (separate) Work Orders that were created at the same time of this request. Include the Work Order number.
    1. See: [↔ How to: Write Effective Notes](https://help.latchel.com/how-to-write-effective-notes)

  3. Proceed to handle the Emergency work order
    1. See: [(⛑OVERVIEW) How to: Handle Emergency Work Orders](https://help.latchel.com/how-to-handle-emergency-work-orders)

  4. _**Scenario Example**_: _Resident has a leak and needs water extraction  Write a note on each work order, referencing that the Work Orders are being addressed separately._

2. **<u>MULTIPLE EMERGENCY WORK ORDERS - OUTCOME 2:</u>** The Emergency requests **do not require different service providers (i.e. the one Service Provider assigned should have the skills required for all of the Emergency requests)**
  1. The Troubleshooter DOES NOT create separate new work orders for each request.
  2. Write a note that indicates that the Service Provider assigned can repair all requests
    1. See: [↔ How to: Write Effective Notes](https://help.latchel.com/how-to-write-effective-notes)

  3. Proceed to handle the Emergency work order
    1. See: [(⛑OVERVIEW) How to: Handle Emergency Work Orders](https://help.latchel.com/how-to-handle-emergency-work-orders)



- **HELP!** If you are having to split the original work order into three or more work orders, or you are unsure on how to proceed, contact the Operations Support Specialist team.
  - Use the Escalation procedure outlined here: [How to: Escalate Between Teams](https://help.latchel.com/how-to-escalate-between-teams)

## [<u>❓</u>](https://help.latchel.com/how-to-handle-emergency-work-orders)Frequently Asked Questions

Q1: What should we do if the SP working on an Emergency for WO informs us they can also handle the Non-Emergency WO for the same property?

Answer: Follow the guidelines below based on subscription type.** **

**Premium Customers:**

If the SP confirms they can handle both work orders, and the work order is in Finding Service Provider status:

1. The team receiving the inbound communication may **directly assign the Non-Emergency WO** to the same SP.
2. Whenever possible, **schedule the appointment during the same call or conversation** with the SP.
3. Confirm whether both WOs can be scheduled **at the same time**, if feasible.

**If scheduling cannot be completed during the interaction:**

- Create a task for the **Ops Associate group** to follow up.
- The follow-up should occur:
  - On the **next business day**, or
  - Within the timeframe specified by the SP (if provided).


**24/7 Emergency, After Hours Emergency, or Autopilot Subscriptions**

1. Create a task for the **PM** stating:
  - The SP has reached out to confirm they can accept the Non-Emergency WO.
  - The SP is already assigned to the related Emergency WO at the property.

2. For additional guidance, refer to:
  - [**<u>How to: Handle Situations for WOs Awaiting PM Action</u>**](https://help.latchel.com/how-to-handle-situations-for-wos-awaiting-pm-action)

3. Inform the Service Professional that we will relay the information to the PM for review. The PM will confirm whether the SP can be assigned to the Non-Emergency WO.

Q2: What if a Service Provider starts working on an additional/separate issue while on-site for an ER WO?

1. **Step 1: **Let the reporter know you appreciate them calling and clarify the current status.
  1. **Say something like:** _“Thank you for the update. Although work has already begun, we’ll need to create documentation to ensure proper tracking and to confirm with the PM how they would like to proceed with the work order.”_

2. **Step 2: **Ask for key information to create the work order, including the following:
  1. **📝 NOTE: **When working on an Assembly ticket, be sure to use all the information provided in the report.
    1. The nature of the issue
    2. The exact location/unit
    3. Who is currently on-site (if they know)
    4. Any additional context they can share


3. **Step 3: **[<u>Create the Work Order</u>](https://help.latchel.com/how-to-create-a-new-work-order-from-incognito-mode-all-submissions)
  1. Be sure to note that the resident stated someone is already on-site working on the issue. This helps avoid confusion later when teams or property management review the ticket.

4. **Step 4: **Verify that the work order has the correct severity. If you are uncertain or if you believe that the issue needs to be reassessed, escalate to the Operations Support Specialists. Refer to [How to: Escalate Between Teams](https://help.latchel.com/how-to-escalate-between-teams)
5. **Step 5: **Escalate the work order to the Property Manager
  1. If the issue qualifies as an emergency
    1. For** PD/EH issues**, attempt to reach the escalation contacts before placing the work order in Waiting for PM (especially if the PM is unresponsive)
      1. Refer to [Job Aid: PM Outbound Communication for Emergency WOs](https://help.latchel.com/job-aid-pm-outbound-communication-for-emergency-wos)

    2. For **non-PD/EH issues or non-emergencies**, create a task for the Property Manager
      1. Subject: **Action Required: PM Instructions or Information Needed**_._
      2. Who is this task about? _Select the PM_
      3. Select a Date and Time: _Leave as is_
      4. Assign to a User Group: _PM user group_
      5. Assign to a User: _Leave as is_
      6. Priority:_ Leave as is_
      7. _Complete task only on Completed or Cancelled job States_
      8. Description: _We’ve created this task for the Property Manager to [insert specific information or instructions needed]. The current status of the work order is [insert status]. Kindly provide the requested information or guidance at your earliest convenience to help ensure a smooth continuation of the process. If you have any questions or need further clarification, please don’t hesitate to reach out. Thank you!_




Q3: A new work order comes in, and a vendor is already scheduled at the same property for a separate WO of the same trade. Can I ask the vendor to also handle the new WO during their existing visit?

This applies when a new work order (emergency or non-emergency) is submitted for a property where a service provider is already scheduled for a separate work order of the same trade (e.g., the SP is coming today for a clogged sink, and a new plumbing WO is submitted for the same property).

**Yes — you should attempt to schedule the same service provider, but do not let the attempt delay handling of the new WO.** Follow the steps below:

1. **Confirm eligibility.**
  1. The existing WO and the new WO must involve the **same trade/skill** (e.g., both plumbing).
  2. Both work orders must be for the **same property**.
  3. The SP's existing appointment should be scheduled within a reasonable window for the new WO's severity:
    1. **If the new WO is an emergency:** The SP's visit must fall **within the 24-hour emergency timeframe**.
    2. **If the new WO is non-emergency:** The SP's visit can be within any upcoming scheduled window.


2. **Attempt to reach the vendor.**
  1. Call the SP using the Latchel Console. Explain the situation and ask if they can also address the new WO during their scheduled visit.
    1. **Say something like:** _"Hi [SP Name], this is [Associate Name] calling on behalf of [PM Company]. I see you're already scheduled to visit [property address] on [date] for [existing WO issue]. We've received a new work order for the same property — [describe new WO issue]. Would you be able to address this during your visit?"_



1. **If the SP answers and agrees:**
  1. **Do not merge the WOs.** Keep the new WO as a separate work order.
  2. Assign and lock in the SP on the new WO.
  3. Set the confirmed appointment on the new WO (matching the existing visit time, or adjusted per SP's input).
  4. Set rate/budget expectations based on the **new WO's severity**.
  5. Proceed to [<u>Step 3: Write Effective Notes</u>](https://help.latchel.com/emergency-how-to-handle-scheduling-requests).


1. **If the SP answers but declines the additional work:**
  1. Thank the SP and let the existing WO proceed as scheduled.
  2. Treat the new WO as a standalone work order — proceed with standard dispatch based on its severity:
    1. Emergency → [<u>How to: Handle Emergency Work Orders</u>](https://help.latchel.com/how-to-handle-emergency-work-orders)
    2. Non-emergency → follow normal dispatch procedures.



1. **If the SP is unresponsive (no answer, voicemail, SMS sent):**
  1. Leave a voicemail and send SMS requesting they call back regarding the new WO.
  2. **Set a 30-minute callback window** — create a follow-up task:
    1. **Subject:** Follow up with SP re: bundling WO
    2. **Who is this task about?** Select the SP
    3. **Select a Date and Time:** 30 minutes from now
    4. **Assign to a User Group:** Troubleshooter
    5. **Priority:** Highest (if new WO is emergency) / High (if non-emergency)
    6. **Complete task on any job state change.**
    7. **Description:** _SP [name] is scheduled at [property address] on [date] for WO [#]. A new [emergency/non-emergency] WO [#] was submitted for the same property (same trade). We called to ask if they can bundle the new WO but received no answer — voicemail and SMS sent. Please call the SP again. If still unresponsive after this attempt, proceed with standard dispatch for the new WO independently._

  3. **If the new WO is an emergency (PD/EH):** Do **not** wait the full 30 minutes — begin standard emergency dispatch immediately (contact other SPs or escalation contacts) while the callback window is open.
    1. If the SP calls back within the window and agrees, follow Step 3 above.
    2. If the SP does not call back or calls back but declines, follow Step 4 above.



📝 **IMPORTANT:**

- **Never delay emergency dispatch solely to wait for a bundling response.** The 24-hour emergency timeframe takes priority. Bundling is an efficiency gain, not a requirement.
- **Keep both WOs separate.** Do not merge them — they may have different severity levels, budgets, rates, and tracking requirements.
- For the reverse scenario (SP already working on-site offers to handle an additional WO), refer to **Q1** above.
