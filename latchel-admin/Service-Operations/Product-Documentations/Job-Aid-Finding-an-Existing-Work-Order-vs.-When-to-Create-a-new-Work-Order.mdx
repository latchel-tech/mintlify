<Note>
We want to prevent duplicate work orders, missed issues, and confusion about ongoing maintenance by ensuring agents always check for existing work orders before creating a new one. The goal is to verify whether a reported issue is already being addressed or if it requires a new work order—so that all related problems are tracked together, service providers are properly informed, and property managers have clear visibility.
</Note>

## 📋 Step-by-Step Process

### Step 1 - Find Existing Work Orders

Before creating a new work order, try to find an existing Work Order under the same property address.

1. Search for the property address in the Latchel console
   1. Copy address of resident
   2. From the Latchel Interface, Click the "Properties" tab. Paste address of the resident into the search bar. - [↔ How to: Navigate Properties Tab in the Latchel Console](https://help.latchel.com/How-to-Navigate-Properties-Tab-in-the-Latchel-Console)
      1. If there is a matching address that shows, Click to reveal the property profile.
         1. Click on the "Maintenance" tab within the Property profile
            1. Check if there is an existing Work Order that the Job Name seems to match the issues described
               1. If there's a potential matching work order, Click on its Job Name and verify if the details provided in the work order description is still matching the details provided.
                  1. Read the Work Order to understand how to best continue, complete, or create a new Work Order based on the original request.
                     1. The agent is responsible for verifying if the additional issue is (1) Related to the skill of the original work order, (2) If a new work order should be created, or (3) If the request needs to be sent to the property manager.
                        1. **OUTCOME 1:** If the maintenance request matches the skill of the Service Provider assigned, then you may add the new maintenance request to the original Work Order.
                           1. If the work order has already been scheduled and the additional work should be added, call the service provider to alert them about the additional work.
                           2. If the work order hasn't been scheduled yet, do not need to call the service provider, just update the work order.
                        2. **OUTCOME 2:** If the skill does not match the skill of the Service Provider on the original Work Order, proceed to Step 3 (Create a New Work Order)
   3. If there's no matching Work Order, Proceed to Step 3 (Create a New Work Order)

### How to Search for Archived Work Orders

1. Go to the Console's main page at [https://app.latchel.com/admin/work-orders](https://app.latchel.com/admin/work-orders), then edit the filter and make sure to select "*Archived Show*":

<Frame><img src="/images/SVC-146.png" alt="Archived Show filter" /></Frame>

2. Enter the property address on the Search bar and filter by list.
3. Change your "*View*" to **list view.**
4. Look for the work orders that have the "**Archived**" State.

<Frame><img src="/images/SVC-147.png" alt="Work orders with Archived State" /></Frame>

## 🎯 When to Break This SOP

You should only deviate from the process in the Job Aid: Finding an Existing Work Order vs. When to Create a new Work Order SOP in specific, documented scenarios:

- If you are working on potential duplicate or recall issues, follow the appropriate SOPs for these cases.
- If you receive direct instructions from a Property Manager, owner, or company leadership that override the SOP: Follow their direction and document the exception.
- If the situation is not covered by the SOP or you are unsure how to proceed: Pause and escalate to Operations Support Specialists for guidance—do not proceed on your own.
