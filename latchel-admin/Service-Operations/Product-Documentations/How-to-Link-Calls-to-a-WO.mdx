## 🧠 What This Process Is Trying to Solve

<Info>
We want to prevent lost information, missed follow-ups, and confusion about which calls relate to which maintenance issues by ensuring every relevant call is properly linked to the correct Work Order (WO) in Latchel. The goal is to make sure all communications—whether made during, before, or after a WO is created—are accurately attached to the right job, so that everyone involved has a complete record of conversations and actions taken.
</Info>

**Content***

## 📋 Step-by-Step Process

### Initiating a call within the WO

1. When initiating a call to a Resident or Service Provider on a Work Order, the call will automatically be tagged to that Work Order.
  <Frame>
    ![image-20240202-212705.png](/images/SVC-85.png)
  </Frame>
  <Frame>
    ![image-20240202-212828.png](/images/SVC-86.png)
  </Frame>
2. If you need to tag it to another Work Order, clip the three-dot menu and check any additional Work Orders.
  <Frame>
    ![image-20240202-213103.png](/images/SVC-87.png)
  </Frame>
  <Frame>
    ![image-20240202-213130.png](/images/SVC-88.png)
  </Frame>

### Placing a call manually

1. When dialing a phone number manually, you must tag the call to a Work Order manually and a banner will appear on the phone dialer to remind you that you need to tag the call.
  <Frame>
    ![image-20240202-213440.png](/images/SVC-89.png)
  </Frame>
  1. Select the related Work Order(s) as required.
  2. If the call is not related to any Work Order, you can scroll down and select “Call is not associated with a Work Order”.
    <Frame>
      ![image-20240202-213558.png](/images/SVC-90.png)
    </Frame>
    1. This option should only be used when the call doesn’t truly belong to a Work Order.

### Tagging past calls to Work Orders

1. When a call has been completed, you can still tag it to a Work Order.
2. From any page in Latchel, click the phone icon in the upper right corner.
  <Frame>
    ![image-20230601-000433.png](/images/SVC-91.png)
  </Frame>
3. This will open your recent calls
  <Frame>
    ![image-20230601-001145.png](/images/SVC-92.png)
  </Frame>
4. Click on the call that you want to link to a WO.
5. The call details will be displayed and you’ll need to click the “Add Work Order” button.
  <Frame>
    ![image-20230601-001354.png](/images/SVC-93.png)
  </Frame>
6. A window with your recently viewed WOs will open where you can select the WO you want to link by clicking the “Add” button.
  <Frame>
    ![image-20230601-001454.png](/images/SVC-94.png)
  </Frame>
  1. Note: You can link multiple WOs to a call.

## 🎯 When to Break This SOP

**Do not break or deviate from this SOP on your own authority.** Always escalate to an Ops Support specialist or follow explicit instructions if you believe an exception is necessary.
