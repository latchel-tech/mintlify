## 🧠 What This Process Is Trying to Solve


<Note>
We want to prevent missed, lost, or delayed escalations and requests by providing a standardized workflow for submitting all Service Operations requests to the Product team. The goal is to ensure every bug, feature request, SOP update, or help article request is submitted through the correct Slack channel and form—creating an official audit trail, reducing channel clutter, and allowing Product and Ops to track, prioritize, and resolve issues efficiently.
</Note>


### Main Audience

Anyone in Latchel Ops escalating an issue or requesting a feature, design, or process/policy change.


### Types of Escalations & Requests

First, determine what kind of request you would like to escalate to the team. Use Table 1 below to figure out the type. If you’re still unsure if something is an issue or a change request, please discuss it with your colleagues or manager.

Table 1: Different Types of Requests


| Escalation or Request Type | Definition | Examples |
| --- | --- | --- |
| Bug Report | Escalation for when something is not working the way that it typically does. | WO not behaving as it should.WOs stuck in Intake processing for more than 3 minutes.Notification sending under incorrect circumstances.Call not being recorded.Certain work orders not appearing on the user dashboard as expected.Tasks created even if it shouldn’t |
| Feature Request | Request to add or change something in the Latchel console that will improve the user’s experience. Please note that these requests should be for things that don’t block any standard work or processes. | Request to add a vendor call history pageRemove task from the overall task list if someone has claimed it or is working on it |
| SOP Update Request | Request to change something in any current SOPs. These do not involve any changes in Tech. | Would be helpful to add a standardized template for speaking to an ownerRequest to have all associates answer webchatsConsolidation request for a specific Slack channel |
| Public Latchel Help Article Request | Request to update or create a Public Help article in [https://help.latchel.com/s/](https://help.latchel.com/s/) for our customers to reference. | Create a page to show PMs how to use the LCN network.Create a page to show Residents how to report issues with WOs.Update a SP help article to correct X error in page. |
| Escalate to Sales | Request about New Property Manager Leads / Sales-related questions | Property Manager/Owner interested in Latchel servicesProperty Manager/Owner  asking for pricingAny indication of a new Property Manager/Owner prospect in Latchel services |
| Diagnostic Flow Issues | Requests related to confusion, redundancy, or errors encountered within the diagnostic prompts during work order creation. | Duplicate or Conflicting Response Options in Diagnostic PromptsRedundant Answer Choices in Diagnostic FlowRepetitive Responses for Same Issue PathInconsistent Option Mapping During WO Creation |

Once you’ve determined the type of request that you’d like to submit to the team, use Table 2 below to identify where the request should be submitted.

| Slack Channel | Escalation or Request Type | Who Submits Here? | Examples |

| bug-report | For any issue when the designed behavior of the application is different than the actual outcome._Important Note: **For all high severity issues that are blocking production and causing critical errors**, please **follow **your normal process of **escalating to **_Operations Support Specialists_. _Operations Support Specialists_ will then conduct a deep dive and escalate in the tech-escalations Slack channel, if applicable._ | Every team at Latchel | See all examples in Table 1 above |

### How to Submit Escalations & Requests

Once you’ve determined which Slack channel to submit your escalation or request to using the table above, you’ll then formally submit the actual request. Here are the general steps of how it works directly below.

**<u>STEP 1: </u>**Press the shortcuts button (lightning bolt at the bottom of Slack channel) to find the form to submit your escalation or request (see orange arrow in the screenshot below).

**<u>STEP 2: </u>**Then, identify which form is appropriate for your request. Please reference Table 3 below for what forms are available in each escalation/request Slack channel. Appendices A-B include the questions from each form.

_Important Note: **If an issue or request is not submitted through one of these forms in the following Slack channels, there is a risk that the product team misses the request.**_

Table 3: Forms in Each Escalation/Request Slack Channel


| Slack Channel | Form | How Form is Used |
| --- | --- | --- |
| bug-report | Bug report | This form is used for issue submissions (i.e. anything that’s not working the way it typically does). **Important**: Every submission requires a video as follows:-Showing the exact steps to reproduce the issue (either the customer showing us live, fullstory video or reproducing the issue with fake data). If this is not possible, the next best scenario is for the reporter to screen share and explain verbally what they are seeing and why they believe its a problem. Pretend like a product manager is looking over your shoulder. What you show them? How do you know its a problem?However, for high severity issues that are blocking production or causing critical errors, please follow your current SOP of escalating to Operations Support Specialists. If the Operations Support Specialist does not determine the issue as an urgent tech escalation, please then submit this issue through this “Bug report” form. |
| ops-requests | Latchel Feature Request | This form is used for any non-issue submissions, which are feature, design or diagnostic workflow requests. |
| ops-requests | SOP Update Request | This form is used for any process/policy change requests or suggestions. |
| ops-requests | Public Latchel Help Article Request | This form is used to request updates to our public Help Center library ([https://help.latchel.com/s/](https://help.latchel.com/s/) . |
| ops-requests | PS SOP Needs Update | This shouldn’t be used by non-Product Support team members. |


<Note>
If you reported a bug, but the issue hasn’t been fixed and you’re blocked from executing your duties, make sure to keep the Operations Support Specialist team in the loop.
</Note>
