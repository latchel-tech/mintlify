## 🧠 What This Process Is Trying to Solve


<Note>
We want to prevent delays, confusion, and dropped maintenance requests caused by missing or unclear details in work orders. The goal is to ensure that every work order contains enough actionable information by providing a clear process for associates to follow when information is incomplete—whether that means reaching out to the resident or property manager for clarification, or properly documenting and closing out un-actionable requests.
</Note>


## Content


## 📋 Step-by-Step Process


### Step 1: Assess if the work order was Resident or Property Manager requested.

1. Check to see if the unit is vacant. If so, then skip to Step 2b: Send to the Property Manager.
2. Most work orders are resident requested. But if you see language that indicates the work order was created by the property manager (example: "INSPECTION" or "unit turn" or "Make ready"), then skip to Step 2b: Send to the Property Manager. Otherwise, go to Step 2a: Send to the Resident.


### Step 2a: Send to the Resident


<Note>
📝 **NOTE**: If the resident reached out via SMS and you are already mid-way through collecting their information via text, you do not need to redirect them to the portal or phone. Continue the intake via SMS. Once you have enough detail (minimum: address + issue description), create the work order via incognito mode. Document that the intake was completed via SMS.
</Note>

6. Submit and you are done!


## **🎯 When to Break This SOP**

**Do not break or deviate from this SOP on your own authority.** Always escalate to an Ops Support specialist or follow explicit instructions if you believe an exception is necessary.
