<Note>
We want to prevent confusion, double work, and missed emergencies when Harmonia creates multiple related work orders from a single resident intake. The goal is to clearly identify project-based work orders and standardize how each related WO is handled—especially when severities differ—so that troubleshooting is coordinated, dispatching is accurate, and residents and Property Managers experience a smooth, consistent process.
</Note>

## 📋 Step-by-Step Process

### Identifying Multiple Work Orders Created from Intake

During the resident maintenance intake process, Harmonia may detect the need to create multiple related work orders from a single submission. When this happens, Harmonia automatically groups the WOs into a project. The Ops team is responsible for reviewing and handling these WOs appropriately.

<Tip>
Always review all open WOs for the property and within the project before calling the resident. This ensures troubleshooting is complete and avoids repeated or conflicting communication.
</Tip>

### How to Identify Project-Based Work Orders

**Project Indicator:**

Below the WO title (main or secondary), you will see a project link.

<Note>
📝 NOTE: Project titles always begin with: "Additional Issues Detected – [Main WO Title]". If more related issues are identified, they will be added to the same project.
</Note>

### Handling the WOs

- For WOs awaiting PM action, refer to the ["How to Handle WOs Awaiting PM Action"](https://help.latchel.com/How-to-Handle-WOs-Awaiting-PM-Action) guide to determine if the PM is actively managing the WO before taking action.
  - If the PM is actively managing it, follow the corresponding guidelines. If not, proceed with the guidelines below.
- Always confirm that the Skill on the secondary work order accurately reflects the issue reported. If it does not, update the Skill to the correct one.
  - For guidance, follow the SOP in ["How to: Choose a Skill"](https://help.latchel.com/How-to-Choose-a-Skill).
- Determine and apply the correct work order severity. Refer to [Service Ops: Handling Work Order Severity via Harmonia & Harmonia X Intake Settings](https://help.latchel.com/Service-Ops-Handling-Work-Order-Severity-via-Harmonia-and-Harmonia-X-Intake-Settings).
  - Emergency: When the secondary work order is flagged as an emergency:
    - The TS member must assign the troubleshooting task to themselves immediately to avoid duplicate efforts.
    - If another TS is already viewing the same WO, post in #ops_info_center channel to confirm who is actively working on it.
    - Refer to [How to: Handle Emergency Work Orders](https://help.latchel.com/How-to-Handle-Emergency-Work-Orders) & [How to: Properly Diagnose Emergency Situations](https://help.latchel.com/How-to-Properly-Diagnose-Emergency-Situations) on how to proceed.
  - Non-Emergency Work Order with Potential Emergency Escalation: When the secondary work order is tagged as non-emergency but may potentially escalate to an emergency (examples include, but are not limited to: water leaks or water remediation):
    - Assess the situation to determine whether the issue meets the criteria for an emergency.
    - If the situation qualifies as an emergency, refer to [How to: Handle Emergency Work Orders](https://help.latchel.com/How-to-Handle-Emergency-Work-Orders)
    - For complex situations: [Job Aid: Troubleshooter Tips for Tricky Situations](https://help.latchel.com/Job-Aid-Troubleshooter-Tips-for-Tricky-Situations)
    - To diagnose and ensure proper classification [How to: Properly Diagnose Emergency Situations](https://help.latchel.com/How-to-Properly-Diagnose-Emergency-Situations)
    - If the secondary WO is not truly a separate issue and appears to be a duplicate, follow this guide: [(⛑EMERGENCY) How to: Handle Duplicate Work Orders](https://help.latchel.com/(⛑EMERGENCY)-How-to-Handle-Duplicate-Work-Orders)
  - Non Emergency Work Order: Proceed with standard handling and no additional action is required.
- Link the call made to the resident with any related secondary work orders, if discussed, for future reference.
  - Refer to [How to: Link Calls to a WO](https://help.latchel.com/How-to-Link-Calls-to-a-WO).

## 🎯 When to Break This SOP

Do not break or deviate from this SOP on your own authority. Always escalate to an Ops Support specialist or follow explicit instructions if you believe an exception is necessary.
