## 🧠 What This Process Is Trying to Solve

<Info>
We want to prevent wasted time, errors, and missed or duplicated maintenance by ensuring associates can efficiently search for, view, and accurately update work orders in the Leo247 system. The goal is to help users quickly locate specific work orders, access all relevant details, and make necessary updates—so that maintenance tasks are managed smoothly, records stay accurate, and nothing falls through the cracks.
</Info>

**Content***

## 📋 Step-by-Step Process

## Searching for a work order

<Note>
The following step-by-step guide assumes you have already logged in to Leo247 and has searched for the “portfolio” you are looking for. Refer to [How To: Add a New Work Order to Leo247](https://latchel.atlassian.net/wiki/spaces/OPS/pages/3115548673/How+To+Add+a+New+Work+Order+to+Leo247) Steps 1-4 on how to login and go to the Property Workspace.

It begins with the process of searching for and viewing work orders.
</Note>

1. From the **Property Workspace**, access the Work Orders section.
  1. **📝** **NOTE*****:***You are in the correct property workspace when you see the view below and the property name displayed on the left side of the page. The name of the workspace will change depending on the portfolio you are viewing.
  2.
    <Frame>
      ![image-20240805-171304.png](/images/SVC-97.png)
    </Frame>
2. This will direct you to the **Work Orders** page, where you can view the list of work orders associated with the selected portfolio.
  1. **📝** **NOTE*****:***By default, the list shows only “**Open**” work orders. To view “**Completed**” work orders, simply uncheck the “**Exclude Completed**” box.
    1. Checking completed work orders helps maintain a comprehensive overview of past maintenance activities. This includes historical references, documentation and dispute resolutions.
  2.
    <Frame>
      ![image-20240805-172243.png](/images/SVC-98.png)
    </Frame>
    1. **Filters tab** - In the Filters tab, you’ll find a filter for each table column. Use these filters to easily search for specific work orders.
    2. **Table Columns**
      1. External ID - This is equivalent to the Yardi ID.
      2. Brief Description - This is a clickable link that will direct you to the detailed work order information.
      3. Property - This is the portfolio where the property belongs to.
      4. Unit - The format is typically presented as “building-unit number.” For example, Unit 033 in Building 07 would be displayed as “07-033.”
      5. Priority - This is the severity of the work order.
      6. Created Date - This is when the work order was created. Note that Latchel follows PST time zone.
      7. Due Date - This information is not applicable for us.
      8. Last Modified Date - This is the date the work order was last updated
      9. Last Modified By - This will show which account made the last update on the work order.

### Search Samples

<Info>
You can enter information into each section of the Filters tab to narrow down and obtain the exact work order results you are looking for.
</Info>

1. **Searching Using the Property Details**
  1. Let us search for all the open work orders for **Unit 033 at Building 07**.
    1. **📝** **NOTE:**While the building number may not be available in Latchel, you can still search for the property using the unit number. Each unit number should be unique within the same property, allowing for effective location and identification of the property despite the absence of a building number.
    2. Enter “033” into the “**Select Unit**” field. You will notice that suggested results will appear.
      1. Select the property you want to search for.
    3. Click the “**Search**” button (magnifying glass icon) in the top right corner of the page to initiate the search.
      1. **‼️IMPORTANT*****:*** *Always click the search button to refresh the search results with the new information you've entered. This step is crucial to ensure that you see the most up-to-date and accurate results based on your search criteria.*
    4. This will display the list of work orders for that property.
    5.
      <Frame>
        ![image-20240805-181646.png](/images/SVC-99.png)
      </Frame>
2. **Search by Job Category for Specific Properties**
  1. The example below demonstrates how to search specifically for **HVAC-related work orders** for Unit 033 in Building 07.
    1. Select the category from the “**All Categories**” tab. Here we will choose “**HVAC”.**
      1. Ensure that “033” remains entered in the unit field.
    2. Click on the “**Search**” button (magnifying glass icon) at the top right corner of the page to start the search.
    3. This will show you the list of HVAC-related work orders for that property.

## Viewing the Work Order

1. To view the work order details, click on the “**Brief Description**” link. This clickable link will take you to the detailed work order page.

## Modifying a Work Order

<Info>
Modifying a work order typically occurs to update details, correct errors, change its status, adjust priorities, or reassign it. These updates ensure that the work order accurately reflects the current state of the task and any new information.
</Info>

1. To update any details, click the “**Edit**” button in the top right corner of the page. This will allow you to begin modifying the work order.
  1.
    <Frame>
      ![image-20240805-183037.png](/images/SVC-103.png)
    </Frame>
2. The fields will become editable, allowing you to update any necessary information.

<Note>
The "**Unit**" field is not editable. If there is a need to update the unit information, please escalate this request to*[pending POC]* for further assistance.
</Note>

<Frame>
