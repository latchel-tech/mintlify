## Definitions

Please see the relevant terms for this SOP and their corresponding definitions below:

- **Agent** - Any member of the Latchel Service Service Operations Team.
- **Work Order (WO)** - A form that contains all information around a maintenance request. Can be submitted by a Resident, PM, or Latchel Agent (on behalf of someone).
- **Task** - An action that needs to be executed for a Work Order. For example, Awaiting Invoice Receipt, Scheduling, Service Provider Left a Note, etc.
- **User** - In this SOP, we refer to the external customers (i.e. Service Provider, PM, Resident, or Owner) as users.


## Description of the UI of the User Work Summary Page


## Header

The header has been newly created so that Latchel Agents have a quick reference to the most important information needed to complete tasks for that person. It is made up of the following. Please note that these have been removed from the original location under the user’s “Details” tab to not duplicate information.

See video walk through for the Header [here](https://www.loom.com/share/29258a14fd1a48ee91f43eb26d633071).


### #1 Name of User

This part of the UI has not changed and is directly editable in the header.


### #2 Phone Numbers

The user’s phone numbers are displayed in this section. If multiple phone numbers are associated with the user, each number will appear directly in the UI. The primary phone number is identified by the **★ Primary** label.


#### Options

1. **Call** – Click this option to call the user.
2. **Video Chat** – Click this option to start a video call with the user. This may be grayed out if the number is not eligible for video chat.
3. **Text Message** – Click this option to send an SMS to the user. This will be grayed out for non-textable numbers, such as landline numbers.
4. **Set as On-Call Number** – Click this option to set the contact number as the on-call number used for on-call alerts.
5. **Delete** – Click this option to delete the contact.


#### Editing Existing Numbers

1. If you’d like to edit a phone number that’s already tied to the user, click directly on the number field and edit.

### #5 Company Critical Note

The company critical note has been brought into the user page for easy reference. Please note that these critical notes will still primarily live on the company page. It’s important to reference these notes before you complete any tasks.

This part of the header remains the same as before. Please use this button to send a webchat to this user.


## Tasks

The tasks tab has been newly designed so that Latchel Agents are able to easily see what they need to work on today vs. later. The purpose of this is to ensure we minimize the number of times we call the same user in a day and eliminate our Latchel Agents doing the same research and/or deep dives.

See video walk through for the Tasks Section [here](https://www.loom.com/share/c02c1b25a77a42f6b27ab1c75c0f5391).
