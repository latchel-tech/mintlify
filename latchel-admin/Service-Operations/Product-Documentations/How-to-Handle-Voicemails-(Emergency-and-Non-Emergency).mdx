<Note>
We want to prevent missed or delayed responses to urgent customer voicemails, whether received by phone or email. The goal is to ensure every voicemail—especially those related to emergencies—is promptly reviewed, accurately documented, and acted on according to urgency and customer type.
</Note>

## 📋 Step-by-Step Process

### How to: Handle Voicemail Tickets

- Open the "Voicemail"
- Press play and listen to it
- If the voice message is accessible:
  - Listen closely and make notes about what the customer says.
    - Who is calling?
      - Can you identify the customer type?
      - Property Manager, Resident, or Service Provider?
    - What does the customer need?
    - Document the call-back phone number of the customer.
  - Find an existing Work Order or Create a New Work Order
    - [(⛑EMERGENCY) How to: Find an Existing Work Order vs. When to Create a new Work Order (Previous Caller)](https://help.latchel.com/(EMERGENCY)-How-to-Find-an-Existing-Work-Order-vs.-When-to-Create-a-new-Work-Order-(Previous-Caller))
  - If the customer is requesting a call back,
    - Understand what is being requested
    - If the customer is not a resident, call them back:
      - If the customer is a resident, send an SMS to the resident first to follow up on the voicemail left.
      - If the resident is not on the Latchel system, call the resident back.
    - If you are unsure, reach out for help to #ops_assistance_hub Slack channel
  - If the customer is just providing information, you don't need to call back.
    - Handle the Customer's information update
      - Refer to [(PREMIUM) How to: Handle Customer Information Updates](https://help.latchel.com/(PREMIUM)-How-to-Handle-Customer-Information-Updates)
  - If there is information missing to make a sufficient update or this is an empty voicemail, call the customer back to ask for the information, except if the customer is a resident.
    - [↔ How to: Make Outbound Calls Within the Latchel Console](https://help.latchel.com/(TECH-101)-How-to-Make-Outbound-Calls-Within-the-Latchel-Console)
    - If the customer is a resident, send an SMS to the resident first to follow up on the voicemail left.
    - If the resident is not on the Latchel system, call the resident back.
  - Remember that Associates should aim to advance the Work Order, i.e. advance the Work Order to the next stage or status ((PREMIUM) Job Aid: Work Order Process Flow)
    - Associates should continue to read the Work Order and see how they can best help the Work Order continue to the next stage in the Process Flow.
      - [(⛑OVERVIEW) How to: Handle Emergency Work Orders](https://help.latchel.com/(OVERVIEW)-How-to-Handle-Emergency-Work-Orders)
- If the voice message is NOT accessible:
  - Refer to [How to: Retrieve Inaccessible Voicemails](https://help.latchel.com/How-to-Retrieve-Inaccessible-Voicemails).

<Note>
If you encounter any issues, escalate to the Operations Support Specialists for validation. If the issue is confirmed, proceed with the workaround outlined below.
</Note>

  - Confirm if a phone number is available.

  - Call the phone number.
    - If contact is successful, proceed to confirm the details of their concern and discuss how it can be addressed.

> Say something like: "Hi, this is [Your Name] calling from Latchel. I'm reaching out regarding a voicemail we received from your office. Unfortunately, we were unable to access the message, so I'm calling to follow up directly. Please let us know how we can assist you."

      - Proceed to assist the customer.
    - If unsuccessful, leave your notes in the Service Provider profile including the Assembly ticket link.
      - Leave a private note in the Assembly ticket about actions taken.
  - If there is no phone number available, leave a private note in the Assembly ticket.

### Document in Assembly

- Leave a private note in the Assembly ticket about actions.
  - Paste the hyperlink to the Work Order.
  - Include information on:
    - "Who was the customer?" "What did the customer state in the voicemail?":"What did you do to Advance the Work Order?"
- Complete the ticket
  - Refer to [Service Ops: Assembly Guide](https://help.latchel.com/Service-Ops-Assembly-Guide) for details

### Document in the Latchel Console

- Include the Assembly ticket number from the voicemail ticket.
  - [How to: Write Effective Notes](https://help.latchel.com/How-to-Write-Effective-Notes)

## 🎯 When to Break This SOP

Do not break or deviate from this SOP on your own authority. Always escalate to an Ops Support specialist or follow explicit instructions if you believe an exception is necessary.
