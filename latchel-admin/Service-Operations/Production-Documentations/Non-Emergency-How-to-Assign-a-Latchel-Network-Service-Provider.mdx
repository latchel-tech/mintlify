## 🧠 What This Process Is Trying to Solve

<Info>
  We want to ensure that non-emergency maintenance requests are assigned to qualified, available service providers from the Latchel Network in a timely and accurate manner. The goal of this SOP is to guide associates through the process of selecting and dispatching the right Latchel Network Service Provider when a preferred vendor is unavailable or the property manager has opted into the network. This process prevents delays, miscommunication, and the risk of assigning unqualified or distant vendors.

  - For information on handling Work Orders in "Scheduling with Vendor" status see: [(PREMIUM) (SOP) Handling 'Scheduling With Service Provider' Tasks](https://latchel.atlassian.net/wiki/pages/createpage.action?spaceKey=ops&title=%28PREMIUM%29%20%28SOP%29%20Handling%20%27Scheduling%20With%20Service%20Provider%27%20Tasks&linkCreation=true&fromPageId=752943255) \$ [(Emergency) How to Handle Scheduling Requests](https://latchel.atlassian.net/wiki/spaces/OPS/pages/3308060699/+Emergency+How+to+Handle+Scheduling+Requests)
  - For information on assigning a Preferred Service Provider, see: [(PREMIUM) How to: Assign a Preferred Service Provider](https://latchel.atlassian.net/wiki/spaces/OPS/pages/781747363/+PREMIUM+How+to+Assign+a+Preferred+Service+Provider)
  - For information on assigning a Latchel Affiliate Service Providers, see: [How to: Source a new service provider](https://latchel.atlassian.net/wiki/spaces/OPS/pages/768999595/How+to+Source+a+New+Service+Provider+Outside+Network+)
</Info>

# 🗂️Definition Matrix

<Info>
  ### About Latchel Contractor Network (LCN) Service Providers

  \*\*\*What's a Latchel Network Service Provider?\*_Latchel Network Service Providers areService Providers_ that are licensed and insured. These Service Providers are invoicing the Property Manager directly, however, contrary to how invoicing works for [Preferred Service Providers](https://latchel.atlassian.net/wiki/spaces/OPS/pages/781747363/+PREMIUM+How+to+Assign+a+Preferred+Service+Provider), Latchel Network Service Providers exclusively invoice using Latchel's built-in invoice system.. Property Managers can Opt-in or Opt-out of using Service Providers from the Latchel Service Providers Network. Latchel Service Providers submit invoices through the Latchel console, so Ops agents never interact with these.
</Info>

For information on the Latchel Contractor Network refer to Types of Latchel Service Providers

## 📋 Step-by-Step Process

## **Step 1: Non-Emergency Steps - Property Manager Instructions**

1. **A Pre-dispatch Instructions box from the Property Manager may pop-up.**
2. If the instructions pop up, follow the instructions to assign the service provider requested by the Property Manager or take any other action that was requested

<Note>
  **ATTENTION**

  If the Property Manager is asking for a specific Service Provider to be used for this work order in the critical notes or pre-dispatch instructions or has asked for it via SMS, email, or phone, first check if that Service Provider was populated in the list of eligible providers based on the skill selected.

  **📝** **NOTE**: If the requested service provider is not showing up in the list, you will need to search for that service provider profile ([_How to: Navigate Service Provider Profiles_](https://latchel.atlassian.net/wiki/spaces/OPS/pages/3265232903/How+to+Navigate+Service+Provider+Profiles)) and check which skill categories this company has. To be able to see that provider in the list, you will then need to update the skill category for the service provider _([↔ How to: Add or Remove Service Provider Skills](https://latchel.atlassian.net/wiki/pages/createpage.action?spaceKey=OM&title=%E2%86%94%20How%20to%3A%20Add%20or%20Remove%20Service%20Provider%20Skills)for instructions) and then restart the service provider assignment workflow (**How to: Navigate the Work Order Interface**for instructions) Then you will be able to select the service provider as they will show up in the list._

  **_If the service provider does not show up after you have added the skill needed to assign, escalate to #problem\_solver\_escalations (Link Pending)_**

  **_If you had to add the skills to the service provider please include that in your notes so we can understand how often this happens._**
</Note>

If nothing pops up, you will assign a Service Provider by following the next step below

## **Step 2: Verify if Property Manager is signed up to use the Latchel Network**

1. If there is no Preferred Service Provide in the list or if we have already attempted to assign all of the Preferred Service Providers for this Property Management company, we will verify if the Property Management company has or not opted into the Latchel Network.
2. Read the Work Order. [↔ Job Aid: Read the Existing Work Order](https://latchel.atlassian.net/wiki/spaces/OPS/pages/757170180/How+to+Understand+the+Existing+Work+Order)
3. Review Work Order Notes for other Service Providers who have already been contacted.
4. **📝** **NOTE:** This step is to prevent Associates from calling Service Providers again extraneously, especially if the Service Provider had already denied the job.
5. Take the time to review the history of Notes from both Associates and System messages.
6. Remember that Service Providers have the option to communicate with Latchel through their own Service Provider Interface
7. How to: Navigate the Service Provider Interface
8. In addition, review whether the Property Manager has "Opted-in" or "Opted-out" of the Latchel Network.
9. Review the Summary Icons in the Property Manager section of the Existing Work Order Interface.

<Frame>
  ![lcn opt.png](/images/SVC-52.png)
</Frame>

2. The Property Manager could have "Opted-in" or "Opted-out" of the Latchel Service Provider Network
3. **"Opt-in"** to the Latchel Service Provider Network
4. If the PM has opted into the Latchel Network, **<u>Proceed to [Step 3](#)</u>**
5. **"Opt-out"** of the Latchel Service Provider Network
6. If the PM hasn’t opted into the Latchel Network,
7. Check SOP - [(PREMIUM) How to: Assign a Preferred Service Provider](https://latchel.atlassian.net/wiki/spaces/OPS/pages/781747363/+PREMIUM+How+to+Assign+a+Preferred+Service+Provider)
8. **Step 4: Cannot Assign a Preferred Service Provider**

## **Step 3: How to Assign a Latchel Network Service Provider**

1. Verify if the work order has a skill assigned - ↔ How to: Add or Edit the Required Skill to a Work Order
2. Depending on the Work Order status, navigate to the screen to assign Service Providers.
3. You can choose Action and select "Find Vendor" or "Set a new confirmed work date"
4. To learn about changing Service Providers depending on the Work Order status (including Scheduling with Resident and Pending Statuses), see this SOP [↔ How to: Reassign a Service Provider](https://latchel.atlassian.net/wiki/spaces/OPS/pages/786859062/How+to+Reassign+a+Service+Provider)
5. Click "Cannot secure preferred vendor for dispatch" to proceed to the Latchel Service Providers list.

<Frame>
  ![lcn search.png](/images/SVC-53.png)
</Frame>

3. The screen for selecting a Latchel Service Provider will appear. This screen will show Latchel Service Providers with the skill required (based on the issue that needs to be resolved) that have completed a previous job either within 25 miles or 50 miles of the property. 

<Frame>
  ![lcn vendors .png](/images/SVC-54.png)
</Frame>

1. Before contacting the Service Providers listed:
2. Note the property ZIP code.
3. Note the trade required for the job (e.g. Plumbing, Electrical, etc.)
4. Navigate to this page: [https://sites.google.com/latchel.com/lcn-lookup/home](https://sites.google.com/latchel.com/lcn-lookup/home)
5. As of December 7th, this is a new tool where new Partner Service Providers can be searched for. These Service Providers take priority over “regular” Latchel Service Providers since Latchel is partnering directly with them.
6. On this page, enter the ZIP code and click search.

<Frame>
  ![image-20231208-030525.png](/images/SVC-55.png)
</Frame>

3. If there are Partner Service Providers in the area, they will appear on the page.
4. Check if any of the Service Providers match the trade required for the Work Order.
5. <u>If there’s a matching Service Provider, take note of the Company name.</u>
6. Return to the Work Order and search for the Service Provider Company you found in the tool.
7. Assign the Service Provider to the Work Order by clicking “Select”. **Note**: There’s no need to contact this Partner Service Provider or set an appointment.

<Frame>
  ![image-20231208-034636.png](/images/SVC-56.png)
</Frame>

3. The work order will move to “Scheduling Service Provider” and the system’s automation will take care of the Work Order.
4. Your job is done with this Work Order
5. <u>If there wasn’t any Service Provider or a Service provider with the required trade,</u> continue to the next step.
6. Assign a Latchel Service Provider listed in the Finding Service Provider screen.
7. Attempt to assign first the SPs with direct deposit

<Frame>
  ![lcn do not use.png](/images/SVC-57.png)
</Frame>

3. You will first review for "Service Providers within 25 miles of property". Contact **DD providers before Issued Cards**. If none appear, proceed to view "Service Providers within 50 miles of property", again contact **DD before Issued Cards**.
4. **📝 NOTE**: Always prioritize **25-mile providers (DD then Issued Card)** before contacting **50-mile providers**.
5. If there is a Latchel Service Provider that qualifies to help with the job type, double-check the work order notes to see if this provider has already been assigned to this job previously. This is to avoid re-assigning a Service Provider that has already denied the job.
6. Click "Select" to choose and assign the Latchel Service Provider.

<Frame>
  ![lcn select.png](/images/SVC-58.png)
</Frame>

1. A Confirmation Page for Selecting that Service Provider will appear.

<Frame>
  ![lcn submit.png](/images/SVC-59.png)
</Frame>

2. Click "Submit"
3. If there is not a service provider listed or you couldn't contact any Latchel Network Service Provider, close the vendor assignment window.
4. Refer to [How to: Source a New Service Provider (Outside Network)](https://latchel.atlassian.net/wiki/spaces/OPS/pages/768999595/How+to+Source+a+New+Service+Provider+Outside+Network+)

## **Step 4: Write Effective Notes**

1. Refer to [How to: Write Effective Notes](https://latchel.atlassian.net/wiki/spaces/OPS/pages/1058211367/How+to+Write+Effective+Notes) for details.
2. Write a Note in the existing Work Order, including the Assembly Ticket # if applicable.
3. The note should summarize the conversation, that you've left a voicemail message, or actions you took to change and assign a new Latchel Network Service Provider.
4. If you have escalated, transferred or deferred the task, your Effective Note should summarize what led you to transfer or defer.

## 🎯 When to Break This SOP

Based on the SOP and related guidance, you can deviate from the process in these cases:

- If the Property Manager **specifically instructs** Latchel to use a **different SP** than what the system has assigned or suggested
