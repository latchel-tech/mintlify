<Note>
We want to ensure that all emergency work orders are attended to promptly by monitoring real-time tasks and notifying troubleshooters when needed. The goal is to prevent delays in addressing critical issues, maintain high-quality service for customers, and keep Latchel operations running smoothly during spikes or unattended tasks.
</Note>

## 📋 Step-by-Step Process

### Process Overview

This is the actual troubleshooting queue for emergency work orders. This also includes emergency follow-ups and immediate emergency dispatches. Note that all emergency work should be handled immediately

1. Review the number of troubleshooters scheduled via the [taskforce file](https://docs.google.com/document/d/1M2vYCDcPv42idwG3YgBypMCWPi7NRlQEO1IzDC6rOco/edit) vs. the number of tasks currently active on the console. To know how many tasks are currently active, update your task filters using this guide: [How to filter emergency tasks](https://help.latchel.com/How-to-Work-the-Tasks-Queue#how-to-filter-emergency-tasks)

2. Check if the troubleshooters that are present have an assigned task being worked on via the Latchel taskbar console:
   - To be able to see how many tasks have been assigned, do not include "unassigned" on your filter option.
   - To be able to see if a task has been grabbed by a troubleshooter, click on the title of the task from the taskbar. This will open the work order and will show you the name of the troubleshooter who took the task.

<Frame><img src="/images/SVC-136.png" alt="Task claimed by troubleshooter on the work order" /></Frame>

<Note>
Note: This has to be done one by one per work order and has to be monitored every 10-15 minutes.
</Note>

3. You can also check emergency work orders that need to be worked on using the [Emergencies Real-time Dashboard](https://datastudio.google.com/reporting/5a2a3b18-61cf-4679-a5c3-4c14f357272e/page/FXltC)
   - Go to the dashboard and choose Emergency WO under the Real-Time drop-down.
   - Select the date and click on apply.
   - From there, you will see the list of Unattended Emergency Work orders. Just click on the Job ID link, and it will take you to the work order that needs attention.

<Frame><img src="/images/SVC-137.png" alt="Unattended Emergency Work Orders list" /></Frame>

<Note>
NOTE: Spikes happen on tasks, and sometimes it takes a few minutes for the troubleshooters to notice since they are on work orders most of the time. It is your responsibility as an Operations Support Specialist to notify the troubleshooters if there are pending emergency work orders that need to be attended to by posting them on the [ops-troubleshooter](https://latchel.slack.com/archives/G0176MVUSNT) channel on Slack.
</Note>

## 🎯 When to Break This SOP

This SOP should guide standard monitoring, but support members can adjust based on real-time situations. For example, if troubleshooters are already addressing a high-priority spike, if the dashboard or console is temporarily unavailable, or if leadership provides a directive to reallocate resources. The key is to ensure emergency work orders are handled without compromising response time or service quality.
