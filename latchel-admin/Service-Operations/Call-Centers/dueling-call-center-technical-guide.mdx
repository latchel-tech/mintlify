## **Call Battle Queries**

**Time to Answer**

```sql lines
SELECT 
date_trunc('week',d.created_at + interval '1 day') - interval '1 day' as week ,
percentile_disc(.9) within group (order by EXTRACT(EPOCH FROM d.updated_at - d.created_at))
from public.dueling_call_center_call d 
where status = 'won'
AND date_trunc('week',d.created_at + interval '1 day') - interval '1 day' = 
'2022-02-20'::timestamp -- update to be week in question
GROUP BY 1
```

**Calls won**

```sql lines
SELECT count (distinct dccc.call_sid)
FROM dueling_call_center_call DCCC
WHERE DCCC.created_at >now()-interval '3 hours'
and dccc.outbound_phone = '9034377682'
and dccc.status ='lost'
ORDER BY 1 DESC
```
