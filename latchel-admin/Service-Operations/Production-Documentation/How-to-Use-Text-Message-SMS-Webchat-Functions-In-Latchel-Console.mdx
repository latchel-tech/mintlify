## 🧠 What This Process Is Trying to Solve

<Note>
  ### What are Latchel Console Text Message?

## About Text Message - Generic Functions

## 💬Text Message

About Text Message

1. <u>What is Text Message?</u>
2. Text Message is a function available to communicate with all customers from the Latchel Console to their mobile phone.
3. When a resident texts in a maintenance request, follow this order:
4. Offer their unique portal link first (from Miscellaneous in their resident profile). This is the fastest path and creates the most complete work order.
5. If they push back or can't use the link, offer intake via SMS (ask the required questions one at a time) or place an outbound call — whichever they prefer.
6. Do not respond with only a phone number or portal link and no further offer of assistance. Always give the resident a clear next step.
7. <u>Who can I send a text message to?</u>
8. You can send a text message to any customer whose phone number is enabled for text messaging.
9. Refer to [Job-Aid: Guide to write SMS/Webchat or email to customers](https://help.latchel.com/job-aid-guide-to-write-sms-webchat-or-email-to-customers) if there’s a warning text next to a message or the number is invalid for texting.
10. <u>How do customers send texts to Latchel?</u>
11. Please refer to [Informational: Latchel Communication (Phone Numbers)](https://help.latchel.com/informational-latchel-communication-phone-numbers) for the appropriate phone number.

## 📋 Step-by-Step Process

### Step 1: How to Identify the Text Message Customer

How to Identify the Text Message Customer

1. When the customer's name is known, the header of the message will populate their name instead of the phone number.
2. Click on the name to reveal the Customer profile.
3. When the customer is unknown, the Associate should be able to click on the phone number and the customer profile (if available) will show up.
4. You can also check the letter between parenthesis before the customer name to identify if it is a Property Manager (PM), or Service Provider / Vendor (V), or a Resident (R)

<Frame>
  ![](/images/SVC-366.png)
</Frame>

4. If there is no identifier on the text message and it doesn't open up when clicked, this may be because there may be multiple people with the same phone number OR it is a number that is not recognized.
5. From the Latchel Console Interface, Click the "People" tab
6. If the context of the message is regarding service provider tasks
7. Click "Service Provider"
8. Copy and Paste the phone number to try to pull up a customer profile that way.
9. Remove any symbols from the phone number including parentheses ( ) and dashes ---.
10. If the context of the message is regarding resident tasks
11. Click "Residents"
12. Copy and Paste the phone number to try to pull up a customer profile that way.
13. Remove any symbols from the phone number including parentheses ( ) and dashes ---.
14. **If none of the above methods work**, ask the customer for more information to locate their related Work Order.
15. Try asking,

<Note>
  **Latchel Blurb** - Oops! I can't locate your customer information. To help us to better serve you, please kindly provide your name and property address. Thank you!
</Note>

### Step 3: How to Assign Text Message to yourself

<Note>
  ### Text Message Tech Feature - Another User is Responding.

  While another user is actively responding to a text message, the text message (all users) will display a field that mentions: "\[username\] is typing...". The purpose of this feature is to prevent multiple users to be handling the same text message, and thereby providing aligned service to our customers.

  If you need to communicate with another user who is (mistakenly) handling the same text message (all users), use Slack and the guidelines outlined in your team's internal communication policy.
</Note>

1. \*\*<u>Always </u>\*\*Send a Response to the Customer (and therefore Assign Text messages to yourself)
2. Upon receipt of the new message from a Customer, Associates should \*\*<u>always</u> \*\*be sending a response to the customer, whether the Associate will handle the text message to completion or not.
3. Send a greeting message, replying to the customer once you begin working on a message.

<Note>
  **Latchel Blurb -** Hello (customer name _if available_)! While I work on your request, feel free to provide us with more details.
</Note>

1. **Note:** Sending a message/reply to the text message will auto-assign the text message to yourself. No other actions are required to Assign the message to yourself.
2. **_Why?_** To avoid team members overlapping work on the same message, Associates handling text message ALWAYS auto-assign the message to themselves upon receiving a message.
3. It also helps the customer to know we are in the process of working on their request.
4. If you cannot handle the Text Message to completion:
5. Proceed to [Step 4](#)

### Step 5: How to Close the Text Message

1. Before closing the conversation, tag it to the appropriate Work Order or Property Manager Company.
2. Refer to [Updated SMS Tagging Designs for Ops](https://help.latchel.com/updated-sms-tagging-designs-for-ops) for details about how the tagging feature works.
3. The conversation should be tagged per the following hierarchy:
4. First to a Work Order(s), this is the most common case.
5. Note: If the conversation happens with an SP who is no longer assigned to a WO, tag the conversation to a PM Company if the SP is preferred or leave it untagged if it’s not a preferred SP.
6. Second to a Property Manager’s company if the conversation does not belong to a WO.
7. Some examples are:
8. Messages from residents not related to a WO.
9. Messages from Preferred Services Providers not related to a WO.
10. Third, you can leave it untagged if the conversation truly does not belong to a WO or Property Manager company.
11. Some examples are:
12. Spam messages from an unregistered number.
13. A Latchel Service Provider wanting to update their account information.
14. If the conversation is already tagged, verify that the tag is correct.
15. Refer to [Updated SMS Tagging Designs for Ops](https://help.latchel.com/updated-sms-tagging-designs-for-ops)
16. If the tag is incorrect, remove it.
17. Refer to [Updated SMS Tagging Designs for Ops](https://help.latchel.com/updated-sms-tagging-designs-for-ops)
18. If the tag is correct, continue with the following steps.
19. **Important:** All conversations need to be tagged properly before ending the conversation.
20. From the open Text Message, click on the three dots on the right-hand side to End/Complete the Conversation, or Close the Window
21. \*\*If you are Transferring the Message to someone else, the message will automatically disappear from your Latchel Console Interface once it has been assigned to someone else. \*\*
22. When the conversation disappears from your Latchel Console, the message has been successfully transferred to another Associate.
23. **<u>"End Conversation"</u> -** Click this option if you are still waiting on a customer reply but would like to completely close out and finish your work in the text conversation.
24. "End Conversations" Unassigns the Associate that had been working on it previously.
25. **IMPORTANT**: Never "End a conversation" if the request is not fully addressed. If you are transferring the conversation to someone else, please DO NOT use this option.
26. \*\*<u>"Close Window"</u> \*\*- Click this option to close the conversation window in the Latchel Console but leaving it active. This option leaves the conversation assigned to you and allows you to access or return to it later.
27. "Close Window" keeps the conversation Assigned to the Associate that last responded.
28. When the customer responds, the messages will be automatically forwarded to you.
