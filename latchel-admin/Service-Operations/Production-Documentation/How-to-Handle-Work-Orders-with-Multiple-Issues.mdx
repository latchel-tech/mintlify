## 🧠 What This Process Is Trying to Solve

We want to ensure work orders with multiple issues are handled efficiently and assigned to the right Service Provider(s). The goal is to provide clear guidance on when to split a work order or keep it together, preventing delays, miscommunication, or missed repairs. This process matters because it helps resolve all resident issues promptly, avoids confusion for Service Providers, and ensures Latchel delivers reliable, high-quality service to customers.

## 📋 Step-by-Step Process

### Step 1 - Assess The Types of Issues Included in the Work Order

Check the work order title and description to see if the work order has multiple issues.

Assess the issues and determine if the issues fit into one or more Skill Category. Simple issues that can be resolved by a handyman, will most likely be resolved with the "Simple Maintenance Skills" Category. Work that is more complex will most likely require a specialized type of Service Provider.

### Step 2 - All Issues Are Simple (or "Handyman" type)

If all of the issues in the work order can be handled with skills within the "Simple Maintenance Skills" Category (or can be handled by a handyman), Edit the work order to select "Simple Maintenance Skills" category and "General Work" skill. Use this SOP to learn [How to: Choose a Skill](https://latchel.atlassian.net/wiki/spaces/OPS/pages/2690088963).

Follow the regular process to assign a vendor:

- [(PREMIUM) How to: Assign a Preferred Service Provider](https://latchel.atlassian.net/wiki/spaces/OPS/pages/781747363)
- [(PREMIUM) How to: Assign a Latchel Network Service Provider](https://latchel.atlassian.net/wiki/spaces/OPS/pages/752943255)

### Step 3 - There is a Mix of Simple and More Complex (or specialized) Issues

If one or more issues within that work order require a more specialized Service Provider, or can't be handled by the Service Providers with the "Simple Maintenance Skills -> General Work" Skills, separate those issues into another work order(s). The work order with the simple issues will be handled as explained in Step 2. The work order with the issue(s) requiring more specialized work will be assigned to the relevant Skill Category, like plumbing, electrical, etc.

<Note>
Note: There might be a service provider that is specialized in two or more Skill Categories that apparently seem unrelated, like HVAC and Pest Control, so select the skill for one of them and see which service providers appear in the list, then to go that Service Provider profile ([How to: Navigate Service Provider Profiles](https://latchel.atlassian.net/wiki/spaces/OPS/pages/3265232903/How+to+Navigate+Service+Provider+Profiles)) and check if they have the other skill, which would avoid separating the work order. In that case, select one of those Skill Categories and select the general skill. Leave notes in the account explaining your choice.
</Note>

To split the work order, use this SOP: [How to: Create a New Work Order from "Incognito Mode" (All Submissions)](https://latchel.atlassian.net/wiki/spaces/OPS/pages/781647909).

If part of the issues can be resolved by one skill category (e.g. plumbing), keep them together in one work order and assign the general work skills within that category.

- See which Service Providers are listed in the Service Provider tool for that Skill Category.
- Double check if that Service Provider has the skills necessary to address each issue within that work order. To do that, go to that Service Provider profile and verify if they have the matching skills for each issue mentioned in the work order. Use this SOP to check on their skills: [How to: Navigate Service Provider Profiles](https://latchel.atlassian.net/wiki/spaces/OPS/pages/3265232903/How+to+Navigate+Service+Provider+Profiles)
- If those issues require different Skill Categories, split them into work orders according to the Skill Category required and select the specific skill.
- If you are having to split the original work order into three or more work orders, or you are unsure on how to proceed, escalate to the Operations Support Specialist team.

Refer to [(Operations) How to: Escalate Between Teams](https://latchel.atlassian.net/wiki/spaces/OPS/pages/776044545)

## 🎯 When to Break This SOP

Do not break or deviate from this SOP on your own authority. Always escalate to an Ops Support specialist or follow explicit instructions if you believe an exception is necessary.
