<Note>
We want to prevent delays, confusion, and missed opportunities for cost savings by providing a clear process for associates to gather additional estimates from service providers when the initial estimate may not fully address the work order or when alternatives are needed. The goal is to ensure that every estimate is thoroughly reviewed, all options are considered, and property managers receive transparent choices—so they can make informed decisions and keep repairs moving forward.
</Note>

## 📋 Step-by-Step Process

### Audit the existing Estimate

The first step in analyzing an estimate is to understand its purpose and context. Consider the following:

**Key Questions:**

- What is the issue outlined in the work order?
  - Review the work order to identify the reported issue. Identify the key problem(s) that need to be addressed. Refer to [How to: Understand the Existing Work Order](https://help.latchel.com/How-to-Understand-the-Existing-Work-Order)
- Does the estimate fully address the problem identified?
  - Check if the estimate specifically addresses the problem outlined in the work order.
- Are all requested services and repairs included?

### Contact the Service Provider

Once the nature of the work order is understood, contact the Service Provider.

Refer to [(TECH 101) How to: Make Outbound Calls Within the Latchel Console](https://help.latchel.com/(TECH-101)-How-to-Make-Outbound-Calls-Within-the-Latchel-Console) and relevant outbound communication guidelines.

Use one of the [A/B Scripts](https://docs.google.com/document/d/1LU-zeBA13NXfZkX7lDdVzJPc3mSj6JWOf9iQr4KVRhQ/edit) to determine the next steps:

- If additional information needs to be added to the estimate note or alternative estimates need to be provided, proceed to the section below → [Add Additional Estimate](#add-additional-estimate).
- If not, document the call by adding a note to the work order.
  - See [How to: Write Effective Notes](https://help.latchel.com/How-to-Write-Effective-Notes).

### Add Additional Estimate

If the service provider states they would like to provide an alternative estimate, proceed with the following steps.

- On the work order, locate the "Service Provider Work Order Link" and open it in a new tab.
- Click "Provide Work Order Update."
- Select "Add Estimate."
- In the next section, enter the ORIGINAL estimate total and description in the provided text box. Then, use the following script:

> "The Service Provider has indicated that [Describe additional/alternative estimate] is a possibility at a cost of [$$$]. If you would like to proceed with the alternative estimate instead please notify a Latchel team member so that we may adjust the work order accordingly."

### Set a Task to Follow Up with the PM

This process will change as the project moves forward.

Initially associates should monitor all completed service provider estimate contacts. When the state changes from "Needs approval" into any later state, associates should send the following SMS to the PM on the property.

> Latchel recently performed an estimate review with the provider on work order "XXXX" and was provided an alternative option for completion. Was this process a benefit to you? Please respond 1=Yes, 2=No

When a response is received note it in the Estimates work file.

## 🎯 When to Break This SOP

Do not break or deviate from this SOP on your own authority. Always escalate to an Ops Support specialist or follow explicit instructions if you believe an exception is necessary.
