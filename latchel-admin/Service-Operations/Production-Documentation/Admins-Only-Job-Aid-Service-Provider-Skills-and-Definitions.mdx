## 🧠 What This Process Is Trying to Solve

<Note>
  ### What is "Service Providers Skill"?

  Each Service Provider is able to provide a list of services and those are described as "skills" in the Latchel Console. "Skills" refer to the abilities or services that a Service Provider offers to their customers. Skills are very specific to what needs to be done to resolve the maintenance request and will be grouped into categories.

  The Skill definition will be describing the issues that the skill can resolve, i.e. examples of when that skill should be used. For example: For skill "Repair ceiling fan", the definition is "ceiling fan is not working, making noises, not mounted properly (shakes)"
</Note>

## Skill Categories

### How to Use this Job Aid

The purpose of this job aid is to enable the ops team to search for skills they will find in the Latchel Console and get more information on what they should be used for.

One way to use it is to look for the Skill Category and skim through it to find the skill you are looking for.

Or you can press "Ctrl" and "F" in your keyboard to open the browser search function and type key words you are searching for.

For each skill category, you will see the name of the skill and the skill definition, which will provide examples of when that skill should be used.
