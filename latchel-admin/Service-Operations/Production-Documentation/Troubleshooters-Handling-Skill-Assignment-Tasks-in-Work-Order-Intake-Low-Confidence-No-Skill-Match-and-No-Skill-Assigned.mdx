## 🧠 What This Process Is Trying to Solve

We want to prevent delays and errors in work order processing when skill assignment issues occur during intake. The goal is to ensure that every work order has the correct skill assigned as quickly as possible, so automation can continue, residents receive timely service, and operational efficiency is maintained.

## **[❓](https://help.latchel.com/how-to-handle-emergency-work-orders)Frequently Asked Questions**

FAQ: What should I do if a noise complaint has no available skill match?

During intake, the system first attempts to identify the source of the noise (e.g., animals, vehicles, HVAC), as this allows selection of the appropriate skill.

- If information is unclear or missing, call the resident for clarification.
- If the noise complaint involves situations such as **domestic violence, vandalism, or trespassing**, and **no applicable skill is available**:
  - Leave the skill field **blank**
  - Proceed with completing the **TS task** generated due to the no-skill match.

<Note>
  **Important:** If the situation appears to be **crime-related or poses an immediate safety risk**, refer to [**How to: Handle 911-Severity Type Work Orders**](https://help.latchel.com/how-to-handle-911-severity-type-work-orders) and follow the required escalation procedures.
</Note>

What should I do if a work order is created and I think it might be non-maintenance?

If you reviewed that a work order created is a non-maintenance request, follow the below steps:

1. **Determine the nature of the request:**
2. If it is clear that the request is non-maintenance (e.g., questions about rent, lease, or other non-repair issues), move to **Step 2**.
3. If it’s **unclear** whether the issue is maintenance-related or not, **call the resident** to confirm.
4. If the resident confirms that the issue is maintenance related, keep the work order and proceed to handle the request.
5. If the resident confirms that the issue is non-maintenance related, proceed to Step 2.
6. If the resident is unresponsive, create a task to the Property Manager using the Action Required task guidelines.
7. Refer to [How to: Put a Job on Hold](https://help.latchel.com/how-to-put-a-job-on-hold)
8. **Cancel the Work Order and resubmit the request following the correct path for non-maintenance requests.**
9. Cancel the work order that was created.
10. Proceed to re-submit the request following the “**Request Non-Maintenance Help**” path.
11. **Notify the Resident (SMS):**
12. **Confirmed non-maintenance request:**_Hi \[Resident Name\], we are reaching out about your submitted work order for “\[Title of the Work Order\].” We reviewed your request and confirmed that it is non-maintenance, so we’ve cancelled the work order and resubmitted your request to your Property Manager. They’ll be handling this directly for you. Thank you and please let us know if we can help you with anything else._
13. **Vague or unconfirmed non-maintenance request:**_Hi \[Resident Name\], we are reaching out about your submitted work order for “\[Title of the Work Order\].” We tried calling to confirm whether this request involves a maintenance issue but weren’t able to connect with you. Since we couldn’t confirm that this is a maintenance-related request, we’ve notified your Property Manager so they can review and assist you with this request directly. If you still need help with a repair, please reply with more details about the problem so we can reopen this as a maintenance work order if needed._
14. **Notify the Property Manager (if necessary):**
15. Only relay the request to the Property Manager if absolutely necessary and it does not fit the above scenarios.
16. For work orders in **“Needs Approval”** status, ensure that a notification is sent to the Property Manager once the work order is cancelled. If no automatic notification is triggered, follow the established process to email the Property Manager’s notification group manually.
