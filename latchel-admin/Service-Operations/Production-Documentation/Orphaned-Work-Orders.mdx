## 🧠 What This Process Is Trying to Solve

<Note>
*We want to ensure that no work orders get stuck without action, which could cause delays, missed follow-ups, or unresolved issues for residents and property managers. By identifying orphaned work orders daily and creating appropriate follow-up tasks, we make sure each job moves forward efficiently. This process reduces the risk of neglected work orders, keeps responsibilities clear, and improves overall service reliability for Latchel and our customers.*
</Note>

## 📋 Step-by-Step Process

### Process Overview

<Warning>
**Prevention Note:** Orphaned Work Orders often occur when a Work Order is updated or reviewed but no follow-up task is created before exiting.\
All associates should ensure a task is in place at all times unless the Work Order is Completed or Cancelled.

For Autopilot WOs, refer to [How to: Handle Autopilot WOs](https://latchel.atlassian.net/wiki/spaces/OPS/pages/2999812097/How+to+Handle+Autopilot+WOs).
</Warning>

An orphaned work order is a work order with no tasks. It is the Operations Support Specialist's responsibility to check them daily and to add an appropriate follow-up task for the work order to move forward.

1. Go to the [Orphaned WOs dashboard](https://lookerstudio.google.com/u/0/reporting/d9160663-a5a3-4f78-936f-75d92cc93fb6/page/p_2yxq1nh54c) and open the list of orphaned work orders.
2. The list will show the work order status, the work order link, the date the job was created, and the last update. Click on each job URL to open the work order.

   <Frame>
     <img src="/images/SVC-594.png" alt="image-20230609-170719.png" />
   </Frame>

3. Once the work order is opened, review the recent updates and create an appropriate task for the work order to move forward, then save the task created. [Job Aid: What is a task?](https://latchel.atlassian.net/wiki/spaces/OPS/pages/2528083973/Job+Aid+What+is+a+task#How-to:-Create-a-Task)

## 🎯 When to Break This SOP

<Tip>
This SOP should generally be followed daily, but exceptions may apply based on operational priorities or system constraints:
</Tip>

- **System or access limitations:** If the Orphaned WOs dashboard or work order link is temporarily inaccessible, document the attempt and complete the process as soon as access is restored.
