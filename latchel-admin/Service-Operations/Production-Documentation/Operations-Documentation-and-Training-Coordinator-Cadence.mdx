## 🧠 What This Process Is Trying to Solve

We want to prevent missed updates, unclear responsibilities, and gaps in training or documentation by providing a structured cadence for the Operations Documentation and Training Coordinator role. The goal is to ensure all key tasks—like SOP creation and updates, training material development, weekly reporting, and communication of process changes—are completed on schedule and with clear ownership.

## Discontinued Processes due to Assembly Transition

### Latchel Library Jira Management (Discontinued due to Assembly transition)

**Frequency:** Daily

**Description:** Collect feedback and update the Jira board

**Specific Actions:**

- Pull up the current list of tasks and tickets in JIRA
- Check on open tickets (will change based on the new process for intake and management)
- Review each ticket and assess (follow the new SOP for feedback intake and management)
- Adjust the status of each ticket based on recent updates.
- Apply necessary changes and update the corresponding SOPs as needed.

**Templates/Links to References/Tools:**

- [JIRA Library](https://latchel.atlassian.net/jira/software/projects/OL/boards/55/backlog)

### Ops product watch

**Frequency:** When updates are available

**Description:** Review product updates impacting operations.

**Specific Actions:**

- The ops-product-watch channel is automatically updated when tickets being worked on by engineering team is updated.
- Open the ticket the engineering is working on by going to the epic
- Read the available information
- Assess if there are impact with operations

## UserPilot In-app Experiences

Userpilot is a product experience software designed to help businesses improve user onboarding, product adoption, and user engagement within their web applications. This is a tool being used when we have additional spotlight/messages that we want to add in our Console.

See [video](https://drive.google.com/file/d/11y0E97uHtleIBxVoksvDBsPLuRsunamp/view) for tutorial, timestamp 19:17

Below are the list of user onboarding elements that were designed in Console.

- [**Enter SP email**](https://run.userpilot.io/flows/153/overview) — This is a message that reminds agents to enter an email when creating a Service Provider account.
- [**Call center non-maintenance pop-up**](https://run.userpilot.io/spotlights/138/overview) — Call center page message to remind agents that they shouldn't use the "Other requests/questions" option during intake.
- [**Do not use internal WO creation page**](https://run.userpilot.io/spotlights/122/overview) — Latchel home screen message to remind agents that they shouldn't use the internal WO creation page.
- [**LVN Perks PM**](https://run.userpilot.io/spotlights/144/overview) — (No longer live) Informational spotlight to remind PMs of the perks of LVN SPs.
- [**Edit approved budget**](https://run.userpilot.io/spotlights/61/overview) — (No longer live) Used to remind agents that approval from owners/PMs is mandatory before increasing the budget beyond the hard limit.
