## **🧠 What This Process Is Trying to Solve**

<Note>
  We want to prevent delays, errors, and miscommunication during the quote analysis process by clearly defining the responsibilities of the Support Team. The goal is to ensure that Operations Support Specialists efficiently gather, organize, and provide all necessary data—such as open cases and price ranges—to associates analyzing estimates, so that every quote is reviewed accurately and on time.
</Note>

## Support Responsibilities

The Operations Support Specialists play a crucial role in gathering and organizing data to streamline the estimate analysis process. Their key responsibilities include:

**1. Running Queries to Identify Open Cases**

- Before running a query, update the date range to ensure only the coverage dates are included. Verify that the query parameters align with the required timeframe.
- Run a query to generate a list of open cases that require estimate analysis.
- Once the query has been executed, download the result file.
- Open the file, highlight the necessary data, copy it, and paste it into [Estimate Analysis](https://docs.google.com/spreadsheets/d/1qgq_IfDzoMJ-lenWjaKBS8NGyCUDi47c8ayzhV0rMVs/edit) file.
- Identify the status of the work order. Any work order must be in "Needs approval", "Forwarded to PM", "Needs Owner Approval", or "Pending" status. All others would indicate an invalid work order.
- Any work order where the estimate was uploaded directly with the PM will not be considered valid.

**2. Retrieving Price Range Data**

- For each open case, run a second query via [chatgpt](https://chatgpt.com/) to obtain price range data based on:
  - Location
  - Issue type
  - Skill required
- Ensure that the price range data is accurate and relevant.

**3. Providing Data to Associates**

- Ensure all extracted data is accurate and formatted properly.
- Remove any duplicate or irrelevant entries before sharing.
- Share the compiled data with the associates responsible for estimate analysis.
- Ensure that associates have all the necessary information to perform a thorough review of the estimates.
