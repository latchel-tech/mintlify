## **🧠 What This Process Is Trying to Solve**

<Note>
  We want to prevent lost files, miscommunication, and delays in resolving maintenance issues by ensuring associates can quickly and accurately upload important documents—like images, PDFs, or other files—to the correct work order in the Latchel Console. The goal is to make sure all relevant information is attached to the work order, clearly labeled, and properly documented, so that everyone involved (residents, service providers, and property managers) has the details they need to resolve issues efficiently.
</Note>

## 📋 Step-by-Step Process

### How to Add a File to the Work Order

<Warning>
  Invoice files must be uploaded using [(Job-Aid) How to: Upload an Invoice for a Work Order - Step 4.2](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/How-to-Upload-an-Invoice-for-a-Work-Order#step-4-1-upload-the-invoice)
</Warning>

1. Rename the file using this format: (#Work Order number)
2. Go to the Existing Work Order in Latchel Console
   1. Locate and Click the Files Tab in the existing Work Order, see this SOP: [How to: Navigate the Work Order Interface](https://help.latchel.com/latchel-admin/Service-Operations/Latchel-Library/How-to-Navigate-the-Work-Order-Interface#how-to-navigate-the-work-order-interface)
3. Click "\+Add File(s)".
   1. <img
        src="/images/image-63.png"
        alt="Image"
        title="Image"
        style={{ width:"76%" }}
      />
4. Select the file(s) you want to upload.
5. Click "Submit"
6. Choose the "File Type" that best describes the uploaded file.
   1. ![Image](/images/image-64.png "Image")
7. Write an Effective Note about what file(s) you uploaded and who you received those files from (and if it was from an email or text message).
   1. Refer to: [How to: Write Effective Notes](https://help.latchel.com/How-to-Write-Effective-Notes)
