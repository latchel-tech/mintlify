## 🧠 What This Process Is Trying to Solve

<Note>
We want to ensure Ops requests are handled accurately and efficiently. The goal is to provide clear steps for taking action on an Ops request ticket in the system, reducing delays, minimizing errors, and improving internal coordination.
</Note>

<Warning>
Operations Support Specialists must only work on these tasks during their ad hoc time.
</Warning>

<Note>
If you need to create a whole new SOP, please utilize the [new approved template](https://latchel.atlassian.net/wiki/spaces/OPS/templates/edit/3537141781).
</Note>

**Content***

## 📋 Step-by-Step Process

Our goal is to minimize the number of pages in the document while maintaining a clear and straightforward SOP structure.

1. A ticket will be assigned to an Operations Support Specialist with the objective of completing it within one week.
2. To access the ticket, open ***Assembly*** and navigate to '**My Inbox.**'
3. Review the request and acknowledge receipt by responding to the ticket. Your timer starts at this time.
   1. **Note: Always start the timer when you are working on a ticket.**
      1. <Frame>
           <img src="/images/SVC-585.png" alt="image-20241212-174140.png" />
         </Frame>
   2. Begin drafting on the Confluence page using the '**Edit**' function, but **DO NOT** publish until the draft has been reviewed. Please refer to the following link for detailed guidelines on how to write a Latchel SOP: [How to Create a Latchel SOP](https://latchel.atlassian.net/wiki/spaces/OPS/pages/770115436/How+to+Create+a+Latchel+SOP).
      1. <Frame>
           <img src="/images/SVC-586.png" alt="image-20241209-215814.png" />
         </Frame>
      2. To confirm you're on the edit page, you will see options to '*Update*' or '*Close*' the document, along with the editor toolbar. This toolbar includes various text formatting tools, allowing you to adjust font style, size, and alignment, insert links, add lists, and perform other document-related actions. These tools help format the text and structure of the document, similar to those found in word processors like Microsoft Word.
         1. <Frame>
              <img src="/images/SVC-587.png" alt="image-20241209-221025.png" />
            </Frame>
      3. **Note:** In some cases, it may be more appropriate to create a new SOP.
   3. Use a **different text color** to make it easier for the reviewer to identify your changes.
   4. Strikethrough (~~sample~~) the information you're recommending to remove (if any), ***do not delete yet***.
   5. See below **example**:
      1. <Frame>
           <img src="/images/SVC-588.png" alt="image-20241212-180532.png" />
         </Frame>
   6. If you don't know how to address a ticket:
      1. You can provide different recommendations and the rationale behind them.
      2. You can tag inform the document coordinator in the ticket for assistance.
      3. Sometimes tickets require input from external departments (mainly CS), in those cases, we'll coordinate obtaining input from them once a recommendation is defined.
         1. Feel free to call out on the tickets when you think it would required input from CS.
4. Once you've completed work on the ticket, **JUST CLOSE THE SOP DRAFT** (this will save your changes without publishing it). Respond within the Assembly ticket to notify the Document Coordinator for review
   1. **Note: Pause/Stop the timer when you're done, or each time you pause work on the ticket by clicking the below button again.**
      1. <Frame>
           <img src="/images/SVC-589.png" alt="image-20241216-205357.png" />
         </Frame>
   2. Refer to this tip when reviewing the draft [How to: Create a Latchel SOP](https://latchel.atlassian.net/wiki/spaces/OPS/pages/770115436/How+to+Create+a+Latchel+SOP#Reviewing-the-draft)
   3. You will be informed if the changes are approved or if further modifications are required.
5. If further modification is required, start the timer again when working on the ticket.
6. If the changes are approved, DO NOT CLOSE THE TICKET. The Document Coordinator will publish and announce the update and will close the ticket.
