## **🧠 What This Process Is Trying to Solve**

<Note>
  We want to prevent delays, errors, and confusion when property managers request refunds for work order invoices. The goal is to provide a clear, step-by-step process for verifying, approving, and processing refund requests—ensuring that each case is handled accurately, documented properly, and communicated transparently.
</Note>

<Note>
  **What is happening before this process?**

  Property Managers will contact Latchel when they want to dispute a maintenance invoice charge. This means the property manager disagrees with something in the invoice and they feel they are entitled to either a partial or full refund due to the issue.
</Note>

<Note>
  If the Property Manager is inquiring about a recall, refer to [How to: Identify and Handle a Recall WO](/latchel-admin/Service-Operations/Production-Documentation/How-to-Identify-and-Handle-a-Recall-WO) for details.
</Note>

## 📋 Step-by-Step Process

<Warning>
  For details on the refund policy, refer to [Latchel Guarantee and Refund Request Policy](/s/topic/0TO5e000000h9wqGAA/Latchel-Guarantee-and-Refund-Request-Policy)
</Warning>

1. The Property Manager has contacted Latchel via email, Webchat, or SMS message stating they want a refund for an invoice or they have an issue with part of an invoice amount. Ultimately the property manager can be disputing part of an invoice or may be disputing an entire invoice and is requesting monetary compensation.
   1. Refer to [this section](/latchel-admin/Service-Operations/Production-Documentation/How-to-Handle-Assembly-Email-Contacts#reply-to-the-email) if the request was received via email.
   2. Refer to [How to: Use Text Message (SMS/Webchat) Functions (in Latchel Console)](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/How-to-Use-Text-Message-SMS-Webchat-Functions-In-Latchel-Console#how-to-use-text-message-sms-webchat-functions-in-latchel-console) if the request was received via SMS/Webchat.
2. You will proceed with informing the Property Manager that they need to submit their refund request by following the procedure outlined on this page: [Latchel Guarantee and Refund Request Policy](/s/topic/0TO5e000000h9wqGAA/Latchel-Guarantee-and-Refund-Request-Policy)
   1. Suggested blurb: "_Hi, \[PM name\]! Thanks for contacting our team, to submit a refund request please refer to the following page, which outlines our refund policy and procedure to request one: [Latchel Guarantee and Refund Request Policy](/s/topic/0TO5e000000h9wqGAA/Latchel-Guarantee-and-Refund-Request-Policy). Let me know if you have any additional questions and I'll be happy to help._"
   2. If the Property Manager insists that we submit the request on their behalf, escalate the issue to Product Support.
      1. Refer to [How to: Escalate to Product Support](/latchel-admin/Service-Operations/Production-Documentation/How-to-Escalate-to-Product-Support) for guidance.

## 🎯 When to Break This SOP

Do not break or deviate from this SOP on your own authority. Always escalate to an Ops Support specialist or follow explicit instructions if you believe an exception is necessary.
