**Terms Glossary:**

**_Direction_**: Inbound-The root user contacts Latchel or Outbound - Latchel contacts the root user<br />**_Phone Number_**: Actual Number utilized<br />**_Used By_**: Who (or what) is dialing or receiving the call<br />**_Purpose_**: When and Why is this number used<br />**_Severity_**: Used to determine criticality of function<br />**_Call Experience_**: Description of what the user encounters when utilizing the number<br />**_Usage_**: Action that is taken when triggered
