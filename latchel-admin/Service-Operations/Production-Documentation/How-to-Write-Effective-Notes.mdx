## 🧠 What This Process Is Trying to Solve

We want to prevent confusion, missed details, and delays caused by unclear or incomplete documentation in work orders and customer interactions. The goal is to ensure every agent writes clear, comprehensive, and well-organized notes that communicate past, present, and future actions.

<Warning>
**No Abbreviations should be used**

No abbreviations should be used in speech (written or spoken) to external customers or internally with other Latchel teams. Special note to avoid using abbreviations for "follow-up", "emergency services", and "non-emergency services".
</Warning>

## 📑 Definition Matrix

**What are Notes?**

Notes - (n.) This document is mostly referring to the published Notes that are found on the Existing Work Order Interface. [(TECH 101) How to: Navigate the Existing Work Order Interface](https://latchel.atlassian.net/wiki/spaces/LTG/pages/440074480)

However, it is Latchel practice to always communicate effectively through the written text portions that are seen by customers, Operations agents, or other Latchel team members for the sake of effective handling of each Work Order.

Use and practice writing text with these guidelines.

**Why write effective notes?**

This is a basic team skill in Operations. Writing communicative notes directly tells other people what's going on with the Work Order tasks. When the agent is being effective in their note writing, other people can quickly understand the Work Order and be able to take subsequent actions quickly without having to research too much.

It's like "passing the baton" when you're doing a baton sprint race. Your teammates are passing the baton to you, and you're passing the baton to someone else.

When your colleague is passing the baton to you, do you want them to leave out details and potentially make the transition sloppy, making it hard for you to grab the baton? Or does the agent set you up with all the necessary details so you can go on with the baton with ease?

What about when it's time for you to pass the baton to a different agent? Are you preparing to set up your colleague perfectly so they can go run with ease, too?

Completing Work Order responsibilities isn't a race to the finish; it is a team effort.

When you're writing an effective note, you're informing (1) agents in Operations, (2) other teams at Latchel, and (3) Property Managers about your Operations agent actions and important details about the customer. Include details about the past actions, your current actions, and future actions with the Work Order.

When other people can clearly understand the circumstances of the Work Order, we are working as a team to reach important levels of customer satisfaction.

## 📋 Step-by-Step Process

### Step 1 - Past Actions

Enter into the Existing Work Order Interface.

Navigate to the Notes section.

When you enter a note into the work order, please make sure you are answering the following questions:

- What is broken/defective in the property?
  - Include the part that is broken (for example: toilet, door, refrigerator, etc.)
  - Clarify the type of issue (for example: leaking, not working, overheating, etc.)
  - Clarify where in the house the issue is located (for example: living room, master bathroom, garage, etc.)

### Step 2 - Present Actions

**Visibility by Property Managers**

When performing Emergency Services, remember that the Property Manager has visibility of all status updates. Writing effective notes regarding these status updates should be informative enough so that when Property Managers are watching agents perform actions live, they can also easily understand the details of agent actions or circumstances of the maintenance request.

What has been done so far? Please include the actions you took:

- Summarize all the actions you have completed (i.e. troubleshoot, asking the resident for availability, assigning a service provider, following up with resident to set availability, following-up with service provider to schedule an appointment, etc.)
- Include how many follow-up calls were made, and who those follow-up calls were for.
- In many instances, you will have completed a number of actions while you are working on a work order. The rule of thumb is, work order notes should be updated as they happen. This way information is not lost or unintentionally altered. If a progression of steps is intentionally being done in one session, only one note needs to be created to summarize everything that occurred.
- If you're assigned to complete a task that agents have already tried before but the solution was NOT effective, escalate immediately.

There are certain required things that you should always include at the beginning of your Notes.

If there are coordinating Assembly Ticket #s, you should always include it in Notes.\
Ticket (###) (action taken) (service provider)/(PM)/(resident)\
i.e. Ticket 1234 called (service provider)\
i.e. Ticket 4321 email from (resident)

If a caller is calling about an existing work order:
- Note the caller's phone number on the WO.

If there are coordinating Work Order #s (in any status), you should always include it in Notes.

When writing effective notes, include the Work Order Number (you don't need to include the URL because the URL doesn't become a hyperlink).

Extra: When asking for helping/escalation in Slack, copy and paste the Work Order URL.

Summarize (in your own words) the conversation that you had via SMS or Webchat with the customer.

<Warning>
**No Abbreviations should be used**

No abbreviations should be used in speech (written or spoken) to external customers or internally with other Latchel teams. Special note to avoid using abbreviations for "follow-up", "emergency services", and "non-emergency services".
</Warning>

### Step 3 - Future Actions

What will we do next?

- If you can't complete an action at this time, explain what actions you took (i.e. the task you created, forward, escalation)
- If applicable, explain when we are planning to execute on that task.
- Again, as described in Step 2, if you're assigned to complete a task that agents have already tried before but the solution was NOT effective, escalate immediately.

### Step 4 - Save Note

Click "Save Note" to finish.
