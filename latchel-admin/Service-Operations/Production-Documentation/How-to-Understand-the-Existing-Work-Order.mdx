<Note>
We want to prevent confusion, repeated mistakes, and missed steps by giving associates a structured approach to analyzing and understanding the current state of any existing work order. The goal is to help Operations agents quickly assess what has already happened, identify who is involved, and determine the next best action—so that every follow-up is informed, efficient, and moves the work order toward resolution.
</Note>

## 📋 Step-by-Step Process

### Step 1

- Review the need of the original request (in Email, text message, or Phone)
- Check if the work order is part of a project.
  - Look beneath the WO title for a project link or any indication that this job is grouped with other WOs from the same intake.
  - If a project exists, open it and review all related WOs so your follow‑up considers all active issues, not just the one you initially opened.
  - For more details, follow [Service Ops: Handling Multiple Work Orders Generated by Harmonia Intake](https://help.latchel.com/Service-Ops-Handling-Multiple-Work-Orders-Generated-by-Harmonia-Intake).
- Are all the issues addressed within the Work Order?
  - If not, does a new Work Order need to be created?
- Who's making the request?
- Status of the Existing Work Order
  - Does the status of the Work Order make sense?
- Read the information provided in the Summary Field.

### Step 2

If the Work Order already exists, connect the dots on what actions have been taken to better understand how to follow-up.

- Review actions - Initial Review - What's been happening lately with the Work Order?
  - Review recent actions (within Notes section of Work Order)
  - Check dates of the actions. How long ago were the actions taken?
  - Check if actions were taken over and over (Is the Work Order incorrectly repeating the same action?)
  - Does this Work Order "make sense"?
  - Does the agent need to troubleshoot a potential emergency maintenance request with the resident?
  - Does the issue seem minor?

**Minor Issues**

In some cases, it would be prudent to reach out to the resident for clarification before doing anything else. Sometimes the issues are very minor. For example, the resident might request a light bulb be changed. Also we need to consider if the request is outside of the apartment in a common area. The property manager my take care of the unit, but not the common areas. Additionally, some requests are not actionable. For example if a resident is asking for the door code to access amenities. Sometimes the work orders are communications. For example "I sent the rent check".

- Review relevant facts - Who's involved in this scenario?
  - Review the job category, Work Order description, and the resident.
    - Edit the title of the work order if it needs more clarification (in keywords).
      - What was the original Work Order description?
      - What issue did the resident call for help about?
  - Review the resident
    - What was the original maintenance request?
    - How many residents are listed?
  - What was the decided job category?
    - Was the job category appropriate?
    - Was the Service Provider assigned appropriate?
    - What else needs to be done for a Work Order that is (Emergency), (Urgent), (Recall), (Other)?
  - Review the Subscription and property manager.
    - What's the Subscription of the Property Manager?
    - Are we upholding the Subscription agreement?
    - Who's the Property Manager?
    - Check Property Manager critical notes.
      - Does the history of notes indicate that the Work Order has followed the instructions in critical notes?
  - Review the Service Provider
    - Is there a Service Provider? What's the status of the Service Provider?
      - Service Provider has been contacted.
        - What happened to the first Service Provider?
          - What needs to happen next?
        - What happened to the second, third, etc. Service Provider?
          - What needs to happen next?
      - Service Provider not been contacted.
        - What needs to happen next?
      - Were there any critical notes about the Service Provider?

### Step 3

- Read notes and history
  - Go to the bottom of the notes. Look at the history, starting from the bottom to the top.
  - Connect the dots on what actions have been taken
    - Check for dates of when things happen
    - Check if we are taking the same actions over and over
    - Check if we are contacting the same person over and over and not getting an answer.
      - If so, check for other residents for that property.
        - From the resident section in the work order, click on the side to see if there are other residents in the drop down menu.
        - If there are other residents, change to someone else.
        - Write an Effective Note about the resident change.
          - You can write: "Changed due to prior resident in the work order being unresponsive".
        - Then re-take the action to that person.
          - For example, try to ask for resident availability again.

### Step 4

- Continue the work order towards completion.
- Use the knowledge from your summary to complete the next task.

## 🎯 When to Break This SOP

Do not break or deviate from this SOP on your own authority. Always escalate to an Ops Support specialist or follow explicit instructions if you believe an exception is necessary.
