## **🧠 What This Process Is Trying to Solve**

<Note>
  We want to prevent errors, delays, and incomplete or inaccurate property records when managing property information in the Latchel Console. The goal is to ensure associates can efficiently search for, view, update, and manage property profiles—including addresses, critical notes, resident information, and work order history—using the Properties Tab.
</Note>

## 📋 Step-by-Step Process

All the tools you need for managing Service Providers in the Latchel Console can be accessed from the link on the navigation bar called Properties

</Expandable>

### Search for Existing Properties

<Expandable title="How to Search for Existing Properties">
  - Find the existing property you are looking for with the search bar.
  - Access/edit property profiles by clicking on the links.

  <Frame>
    ![Accessing property profiles](/images/SVC-269.png)
  </Frame>

  - If no results are found, make sure you click on "Show Disabled Properties" since the property you may be looking for is already disabled.

<Expandable title="How to Merge Duplicates">

### Enable/Disable a Property Address

<Expandable title="How to Enable/Disable a Property Address?">
  On the Property page, you will find the option to enable or disable property addresses.

  To enable or disable a property address, click the three dots located at the top-right corner of the page. From the dropdown menu, select the appropriate action (Enable or Disable property). Be sure to include notes explaining why the property was enabled or disabled.

  <Note>
    Note: Always refer to the relevant SOPs to determine when Operations is authorized to enable or disable a property.
  </Note>

  <Frame>
    ![Enable or Disable property option](/images/SVC-278.png)
  </Frame>
</Expandable>

### Details Tab

<Expandable title="Details Tab">
  The bottom portion of the page is open to the Details tab by default.

  The left side of the Details tab contains editable information about the property. All of the sections are expanded by default.

  <Frame>
    ![Details tab expanded sections](/images/SVC-279.png)
  </Frame>

  **Two Different Addresses on the Property Page**

  - If you see two addresses on the property or work order page, this means the original integrated address differs from the one stored in Latchel. Ops associate must always follow the Latchel address as this is the primary address for service coordination.

  <Frame>
    ![Two different addresses on the property page](/images/SVC-280.png)
  </Frame>

  - Source Address (1st Address) – The address submitted by the Property Manager and recorded in their Property Management system.
  - Latchel Address (2nd Address) – The address stored in the Latchel system, which is visible to the Service Provider.
  - If there is a discrepancy between the Source and Latchel address, but the Latchel address is correct, no further action is needed, and a PS ticket is not required.
  - If the Latchel address is incorrect (either confirmed by the resident, service provider or PM/Owner), Ops should update it to the correct address and add a note on the property page explaining the reason for the update.
</Expandable>

### Residents Tab

<Expandable title="About the Property Residents Tab">
  The Residents Tab lets you view all residents for that property. If there are any residents occupying the unit, they would be listed here.

  <Frame>
    ![Residents Tab](/images/SVC-286.png)
  </Frame>

  Resident move-in/move-out - This should be used whenever you get a message from someone saying they no longer live at the property. You can set their move out date to a time in the past (or set it to yesterday) so that we no longer message them.

  - Scroll down to the Residents section and click the "..." icon next to the appropriate Resident

  <Frame>
    ![Resident options menu](/images/SVC-287.png)
  </Frame>

  - Click "Edit Resident Move Dates" and set appropriate times or set to a "yesterday" move out date if they no longer live there.
</Expandable>
