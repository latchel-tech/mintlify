## 🧠 What This Process Is Trying to Solve

<Info>
  We want to ensure the right people are notified for property issues and updates. The goal of the "How to: Locate the 'Default Notification User Group' contact(s)" SOP is to help associates quickly identify which user group will receive notifications for a property. This prevents missed or misdirected communications, reduces delays in response, and ensures our customers always reach the correct contacts for timely support.
</Info>

**Content**\*

## 📋 Step-by-Step Process

1. Navigate to the corresponding property page.
2. Locate the “Maint. Communication Settings section”.
3. Note the “Default Notification User Group” name.

<Frame>
  ![image-20230524-220715.png](/images/SVC-60.png)
</Frame>

1. **📝** **NOTE**: It is common it will be named “Default User Group” but it can vary.

<Frame>
  ![image-20230524-221056.png](/images/SVC-61.png)
</Frame>

4. Locate the “Property Manager” Section.

<Frame>
  ![image-20230524-221824.png](/images/SVC-62.png)
</Frame>

5. Navigate to the Property Manager page.

<Frame>
  ![image-20230524-221904.png](/images/SVC-63.png)
</Frame>

6. Once you’re on the Property Manager’s page, navigate to the “User Groups” tab.

<Frame>
  ![image-20230524-222020.png](/images/SVC-64.png)
</Frame>

7. Inside the User Groups tab, search for the specific User Group name you noted earlier in this process.

<Frame>
  ![image-20230524-222136.png](/images/SVC-65.png)
</Frame>

8. All the members listed in this User Group will be notified whenever this group is contacted.
