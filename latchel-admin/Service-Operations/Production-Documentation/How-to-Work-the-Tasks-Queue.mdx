## 🧠 What This Process Is Trying to Solve

<Note>
  We want to prevent missed tasks, duplicate work, and delays in resolving customer issues. The goal is to ensure every associate efficiently filters, claims, and completes tasks in the queue—so nothing falls through the cracks and customers get timely, accurate service from Latchel
</Note>

<Note>
  Note: You can refer to [Job Aid: What is a task?](/latchel-admin/Service-Operations/Production-Documentation/Job-Aid-What-is-a-task) for a brief overview of what is a task and its components.
</Note>

## 📋 Step-by-Step Process

<Note>
  **⚠️Before you begin**

  **Verify You Are on the Correct Work Order**

  Before taking any action on a task, confirm that the task is associated with the correct Work Order. Cross-reference the task description and the details of the work order.

  Tasks may occasionally be assigned to the wrong Work Order. If you identify a mismatch, ensure to take the action on the correct work order.
</Note>

### **How to pick up your next task**

Associates no longer need to manually set up Console filters to find and claim tasks — this is now handled by the Latchel Service Ops Assistant plugin.

1. Confirm your Latchel status matches the work you're covering (e.g., Non-Emergency Tasks, Emergency Tasks) — the plugin uses this to decide which queues you're shown.
2. Open the Latchel Service Ops Assistant and go to **Next Task**.
3. Review the task's urgency, due date, and work order context.
4. Click **Assign me & Go** to claim the task and jump directly into the work order.

The plugin applies the correct priority order automatically (Troubleshooter queue, then emergency status, then Urgent flag, then Priority, then age) — you no longer need to manually sort by age or filter by "Due: Overdue."

**If Next Task comes up empty:** check **Future Tasks** on the queue card before assuming there's nothing to do. Future Tasks includes both deferred tasks and tasks that were freshly created with a later due time. If the task description doesn't give a specific reason for the later due time and you have the time and ability to act, work it now — not-yet-due doesn't mean don't touch. If the description does give a reason (e.g., "resident asked to be contacted tomorrow"), that reason still applies and you should wait.

See [<u>\[(Operations Associate) Job-Aid: Latchel Service Ops Assistant Plug-in\]</u>](https://help.latchel.com/latchel-admin/Service-Operations/Operations-Associate-Job-Aid-Latchel-Service-Ops-Assistant-Plug-in#operations-associate-job-aid-latchel-service-ops-assistant-plug-in "https://latchel.atlassian.net/wiki/spaces/OPS/pages/4227629058") for the full walkthrough.

#### What do you do next?

1. For troubleshooting tasks refer to: [How to: Handle Emergency Work Orders](/latchel-admin/Service-Operations/Production-Documentation/how-to-handle-emergency-work-orders)
2. For other types of tasks, refer to the individual instructions of the task.
3. When you’re done with the task, and before taking another one, be sure to refresh the task queue by clicking the refresh button:

<Warning>
  If the task has to be deferred, please ensure that you unassign the task by clicking the 'x' button after your name so that it returns to the unassigned group and can be handled again when the time is due.
</Warning>

### Handling the Task

<Note>
  Once you've claimed a task via **Next Task**, you're taken directly into that work order — but don't act on it in isolation. A property or resident may have multiple maintenance requests, and Residents, Service Providers, and Owners can each have multiple open tasks across different work orders at the same time. This applies to both emergency and non-emergency work orders.
</Note>

<Warning>
  Before taking action, use the **View Open Tasks** button under the contact to see everything else open for that same person. Review and discuss all pending tasks for the day for the specific contact you're calling — this resolves everything in a single interaction and gives the customer a more efficient, seamless experience.
</Warning>

<Warning>
  ### ✅ Prevent Orphaned Work Orders (No-Task WOs)

  **A Work Order must never be left with zero open tasks unless it is Completed or Cancelled.**

  If your action requires waiting (resident/SP/PM response), you must:

  1. **Defer the existing task**, OR
  2. **Create a new task** that matches the Work Order’s current status and next step.

  For Autopilot WOs, refer to [How to: Handle Autopilot WOs](/latchel-admin/Service-Operations/Production-Documentation/how-to-handle-autopilot-wos).
</Warning>

### What should be done if an associate needs to release a Work Order due to unforeseen problems?

This typically occurs when there's a language barrier (e.g. an English-speaking associate encountering a Spanish-speaking Resident), or the associate encounters a system issue that prevents them from completing the assignment.

1. The associate needs to notify Operations Support Specialists by posting the work order, detailing the actions they've taken and the problems they're facing, in the #ops-troubleshooter channel for emergency work orders and in the #ops\_associate\_escalations channel for non-emergency work orders.
   1. Refer to [How to: Escalate Between Teams](/latchel-admin/Service-Operations/Production-Documentation/how-to-escalate-between-teams)
2. Unassign the ticket task from yourself by editing the task as shown above.
   1. The work order returns to the task queue, and anyone available should pick it up — it'll surface automatically via Next Task to available associates.
   2. Note: If there's a language barrier, the Operations Support Specialist team may tag associates who can handle the task.

<Note>
  **Actions to Take When Associates are Working on Non-Emergency Tasks:**

  Whenever you work on a task, kindly remember the following steps:

  1. **Always Call First (**_Unless SOP states otherwise or there's a clear indication in the task that a call may be inappropriate, do not skip this step.**)**_
     1. **For Residents:** Call between 8:00 am and 7:00 pm property time is allowed.
     2. **For Service Providers:** Call between 8:00 am and 5:00 pm property time. Always check critical notes (e.g., Puls' office hours start at 7 am, so you can call them already).
     3. **For Owners (Nomad & RentRedi only):** Call between 8:00 am and 5:00 pm property time.
  2. **If You Tried to Contact Them via Phone Call and the Contact Didn’t Answer:**

     1. Always leave a voicemail if applicable.
     2. Then attempt to reach the contact via text message and email.
     3. **For Service Providers:** Outside business hours, send an email only for non-emergency situations.
     4. **Note:** Only after completing these steps can you defer the task. Note that in some cases, tasks should not be deferred and must continue to follow the corresponding process or SOP.

  FOR **EMERGENCY WORK ORDERS** please refer to: [How to: Handle Emergency Work Orders](/latchel-admin/Service-Operations/Production-Documentation/How-to-Handle-Emergency-Work-Orders)
</Note>
