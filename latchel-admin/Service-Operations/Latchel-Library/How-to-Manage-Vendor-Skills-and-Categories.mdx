## Objective

<Info>
The objective of this document is to provide Latchel Administrators with a guide on how to manage Vendor Skills and Skill Categories.
</Info>

<Note>
Only a Latchel Admin can change, add, or remove skills and their categories from the Latchel System. If you are not an Admin, submit your request by following [↔ How to: Request Changes or Maintenance to Vendor Skills](/How-to-Request-Changes-or-Maintenance-to-Vendor-Skills)
</Note>
**All Skill Maintenance is done from the Administrative Menu in the Latchel Dashboard.**

<Frame>
  <img src="/images/LL-101.png" alt="Image" />
</Frame>

Requested changes should be available in the Slack channel #skills-and-troubleshooting-maintenance
Admins can view requested skills maintenance in the backlog here. [https://latchel.atlassian.net/jira/software/projects/SPSM/boards/10](https://latchel.atlassian.net/jira/software/projects/SPSM/boards/10)
All changes should be documented on the Skills Maintenance update log to be shared in the Weekly Updates (Link-Pending)

<Warning>
Each change will go live as soon as it is made. This means it will immediately show for anyone who refreshes their page and attempts to assign a skill.
</Warning>

### Step-by-Step Guide

#### Step 3- How to Change/Add Skill Category
The first thing you see when you open the Service Provider Skills menu is a list of all the existing skill categories

<Frame>
  <img src="/images/LL-102.png" alt="Image" />
</Frame>

To add a skill category,
1. Select the "New Skill Category" button in the upper right corner 
<Frame>
  <img src="/images/LL-103.png" alt="Image" />
</Frame>

2. Simply add the name of the Skill Category you wish to create and Save

#### Step 1-How to Add a New Skill
1. Select the Skill Category you wish to add a skill to 
<Frame>
  <img src="/images/LL-102.None" alt="Image" />
</Frame>

2. Select the "Add New Skill" button 
<Frame>
  <img src="/images/LL-104.png" alt="Image" />
</Frame>

3. Fill out the Skill Name and Description of the Skill you wish to create 
<Frame>
  <img src="/images/LL-105.png" alt="Image" />
</Frame>

4. Save the skill

#### Step 2- How to Change Skill Descriptions
1. Select the skill category your skill is in 
<Frame>
  <img src="/images/LL-102.None" alt="Image" />
</Frame>

2. Select the skill from the list of skills 
<Frame>
  <img src="/images/LL-106.png" alt="Image" />
</Frame>

3. Select the three dots on the right of the screen  
<Frame>
  <img src="/images/LL-107.png" alt="Image" />
</Frame>

4. Select Edit
5. The Skill Name and Description are directly editable fields. Make the corrections and save 
<Frame>
  <img src="/images/LL-108.png" alt="Image" />
</Frame>
