  <Frame>
    ![Image](/images/LL-47.png)
  </Frame>

  - **Owners**
    - This link brings up property owner’s information. Latchel Associates are normally not contacting the Property Owner, and should be using this tab minimally.

  <Frame>
    ![Image](/images/LL-48.png)

  <Frame>
    ![Image](/images/LL-49.png)
  </Frame>

  - **Residents**
    - This link brings up a searchable list of Residents with contact information.  You can drill down into resident member profiles by clicking/tapping the links in the **Name** column.

  <Frame>
    ![Image](/images/LL-50.png)

### **Tasks Queue**

<Accordion title="About the Tasks Queue">
  - Click the Clipboard in the upper right corner to bring up the task queue. Only Internal team members handle Tasks. Further navigation can be found at [↔ How to: Handle Tasks from the Latchel Console](/Latchel-console)

  <Frame>
    ![Image](/images/LL-56.png)
  </Frame>

  - For more information on how to handle tasks from the Latchel Console, see this SOP: [(SOP) How to: Handle Tasks from the Latchel Console](https://latchel.atlassian.net/wiki/spaces/LTG/pages/1025442827/SOP+How+to+Handle+Tasks+from+the+Latchel+Console)
  - Review Task "Viewed" Icon on the Work Order in this SOP: [Task Filtering the eyeball (viewed) icon](#)[.](https://latchel.atlassian.net/wiki/spaces/OM/pages/440074480/TECH+101+How+to+Navigate+the+Existing+Work+Order+Interface#id-\(TECH101\)Howto:NavigatetheExistingWorkOrderInterface-NotesandTasks)
  - **Location and Elements of the task queue**
    - **The tasks can be located in the Latchel Console. They may be hidden by default and the "clipboard" must be selected in order to reveal all tasks.**

  <Frame>
    ![Image](/images/LL-57.png)
  </Frame>

  - The list will appear on the right side of the screen.

  <Frame>
    ![Image](/images/LL-58.png)
  </Frame>

  - The tasks will be ordered by priority, then severity then due date
  - When clicked, the task will expand and offer more information on the task, who should be contacted (if anyone), and the link to the job. This is what you will mostly see:

  <Frame>
    ![Image](/images/LL-59.png)
  </Frame>

  - Manual Refresh button: New tasks show up with the refresh button. After completing the task, hit refresh.
    - It is a good practice to hit the refresh button after completing each task, so you know the next task you are working on is the one with highest priority

  <Frame>
    ![Image](/images/LL-60.png)
  </Frame>

  - **Filtering the Tasks**
    - You can filter the tasks by various different criteria.
      - You can select to filter tasks that are overdue, i.e. passed the deadline to complete the task that was set when the task was created
      - You can select to filter tasks by "Jobs" or by "Invoices" (see drop-down menu "for")

  <Frame>
    ![Image](/images/LL-61.png)
  </Frame>

  <Frame>
    ![Image](/images/LL-62.png)
  </Frame>

  - **Definitions**
    - **Priority:**
      - Refers to a prioritization criteria applied to all tasks by the Latchel Admin team. The priority field is set in the back-end and is not visible to Lachel users, except admins. Property Managers can only edit a task’s priority if the task is assigned to a group within their company
      - Tasks will have different priority levels (Lowest, Low, Medium, High, Highest). The rule of thumb is that tasks related to scheduling will receive highest priority

  <Frame>
    ![Image](/images/LL-63.png)
  </Frame>

  - **Severity**
    - Refers to how the job is being classified in terms of being normal, urgent or emergency. Right now, this is called "Job Priority" but there is a request to update it to "Job Severity"
  - **Age**
    - Refers to how long the task has been overdue. If the task was not resolved by the due date, it will start aging in the system
  - **T-Code**
    - The T-code is the class or group that is responsible for working that task. This will not show assigned tasks.  They are split as follows:
      - T1- The Tier 1 team
      - T2- The Shift Support team
      - T3- The "Customer Success" team
      - TPM- Property Manager responsibility

  <Frame>
    ![Image](/images/LL-64.png)
  </Frame>

  - **Note**: T-Code is being replaced with "User Group"
  - **User Groups / My Groups**
    - Tasks will be assigned to user groups based on how our operations team is organized, which helps to see which tasks should be handled by a specific group of individuals. The assignment to a user group can happen automatically or will need to be assigned manually.
    - Each operations team member will be assigned to one or more groups. By clicking on "My Groups" you will see all tasks assigned to all groups you are a part of.
      - \*\*

  <Frame>
    ![Image](/images/LL-65.png)
  </Frame>

  - **Assignee**
    - Assignee filters the code by the user it is assigned to. This is mostly used by the Shift Support and Management to oversee task workload, but could also be used to see any task assigned directly to any user. Tasks in this view will not show up in the T-Code view.
    - You can "Assign" or "Unassign" a Task by going to the task and editing that field: [(SOP) How to: Handle Tasks from the Latchel Console](https://latchel.atlassian.net/wiki/spaces/LTG/pages/1025442827/SOP+How+to+Handle+Tasks+from+the+Latchel+Console)
  - **Property**
    - This selection filters the task queue by individual properties. This is useful for the agent to be sure that any task they are working on is the only one for a property.

  <Frame>
    ![Image](/images/LL-66.png)
  </Frame>

  - **TimeZone**
    - This filters tasks based on local time and is helpful to avoid contacting customers outside of business hours or at inappropriate times
  - **Contact**
    - This selection filters by contact,which is the person we need to communicate with to resolve this task

  <Frame>
    ![Image](/images/LL-67.png)
  </Frame>

  - **View filters applied**

  <Frame>
    ![Image](/images/LL-68.png)
  </Frame>

  - **Close the Task**
    - For more information on how to Close the Task, see this SOP: [(SOP) How to: Handle Tasks from the Latchel Console](https://latchel.atlassian.net/wiki/spaces/LTG/pages/1025442827/SOP+How+to+Handle+Tasks+from+the+Latchel+Console)
</Accordion>

### **User Status**

<Accordion title="User Options">
  - The final option on the nav bar is a user status menu that you can use to sign-in or logout.

  <Frame>
    ![Image](/images/LL-69.png)
  </Frame>

  1. The statuses are:
     1. **Available**- This means the user is available to receive calls
     2. **On Break**- This means the user is not available to take calls
     3. **In a meeting**- This means the user is not available to take calls
     4. **Unavailable**- This means the user is not available to take calls
        1. This is the default status for all users on login
     5. **On a call**- This means the user is on an active call
        1. The user cannot select this status, instead this status is selected for them when they are on an active call
  2. Activity Icon - In front of the user initials displays a small circle that changes color,
     1. **Green icon** - Status "Available"
     2. **Orange icon** - Statuses "In a meeting" and "On a Call"
     3. **Red icon** - Statuses "Unavailable" and "On Break"
  3. As an Admin user, I can update other peoples' status, too!
  4. The timestamps for when a user enters in or out of one of these statuses are logged in the database
</Accordion>

### **Dashboard Views**

<Accordion title="About the Dashboard Columns">
  1. By default, work orders are presented on the dashboard in columns organized by six different status groups: **Pending**, **Scheduling**, **Work Date Scheduled**, **Confirming Completion**, **Getting Invoice**, **Completed, and Cancelled**
  2. In this view, each work order is presented in a box containing: (1) work order number, (2) work order title, (3) property address, (4) current status, (5) duration of time, (6) work order severity, and (7) service provider.  You can click on the work order to view details and/or take action on the work order.

  <Frame>
    ![Image](/images/LL-72.png)
  </Frame>

  2. If there are many work orders in a single column, use the vertical bar on the right side of the column to scroll down and view more jobs.

  <Frame>
    ![Image](/images/LL-73.png)
  </Frame>

  About the List ViewClick the **List icon** to change to the alternate view.

  <Frame>
    ![Image](/images/LL-74.png)
  </Frame>

  In this view, each work order is presented as a single line item, and the **Job Name**, **Resident**, **Service Provider**, and **Property Manager** columns are all clickable for additional detail.

  <Frame>
    ![Image](/images/LL-75.png)
  </Frame>

  In addition to the search bar, the list view also has an option to filter results by status.  Select the button to the right of the column view button to access the filters.  _Note: By default, cancelled work orders are not included in search results.  You can add cancelled order to your search results using the filters feature._

  <Frame>
    ![Image](/images/LL-76.png)
  </Frame>
</Accordion>
