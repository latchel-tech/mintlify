- My appfolio sync isn't working?
- Why are work order from Latchel not showing up in Appfolio?
- Why are my Appfolio work orders not showing up in Latchel?
- Go to confluence and choose sql query 2. This will return all information back to us when using PgAdmin
- Go to Tools icon and click scroll down and click query tools this will open a screen where you may place your copied sql query 2.
- Replace the company ID with whichever property is in need of information. ( Company ID located in address bar when pulled up in Stage.)
- Download the results for best viewing
- Open the download and scroll over to ref_property_id and ref_unit_id
- Information must match exactly, if there is NULL showing up in the report the Appfolio sync will not work
- Escalate to tech before taking further action. Once the source problem is determined, we can begin to “merge” the properties back together to resolve the syncing issue
- Latchel must be added as a user to their platform as a maintenance manager (logged in)
- Refer to the onboarding specialist if they have continued problems with the sync
- New work orders must be assigned to Latchel
- Sync’s are not instant, the first layer of information that is processed is property information, then work order information is processed. This can take 20 minutes to a couple hours depending on how much information is being disseminated.
- If the customer wants work orders in the past synced to Latchel, we will have to instruct the customer to go to the plug in set the date back to when desired work order was created and run the sync with the past date selected. This will pull any work orders from any span of time in the past and sync them with Latchel.
2. [https://drive.google.com/open?id=10aG1ibrZoltMAoKtqJ58V5a_IA1FoZdh](https://drive.google.com/open?id=10aG1ibrZoltMAoKtqJ58V5a_IA1FoZdh)
- Syncs keeps resident and property data up to date within Latchel
- Syncs also keep work orders up to date
- Within Appfolio there is a floating Latchel icon once the plug in is installed.
- Below the Latchel icon there is a sync all data, make sure to set the date back to capture any work orders in the past that customer would like to sync to Latchel
- 30 second to a minute to gather property data, goes through several phases. Gathering property data, importing properties to Latchel, gathering work order data, creating work orders in Appfolio, importing work orders to Latchel.
- As a CS manager you can check the sync by going to Admin and click Imports.
- Look for the customer in question and you will be able to see their latest sync. You will be able to see the status and the “numbers” of information being processed. Once the “numbers” match the sync is complete.
