## **Purpose**

<Info>
  The purpose of this is a guide on how to navigate the sections and tabs within an existing Work Order within Latchel.
</Info>

<Note>
  While the main components of a Work Order Detail page will always be the same, the actions that are available for you to take and the fields that appear as editable to you are dependent on the Priority Status of the work order and your agent tasks.
</Note>

### Main page

This is an overview of the page of a WO and its components when you first open it.

<Frame>
  ![Image](/images/LL-150.png)
</Frame>

1. Side Panel
2. Current tab active (usually the “Details” tab by default)
3. “Action“ dropdown menu
4. Task(s) notification

### Side Panel

The side panel contains general information about the WO and allows you to navigate to the different tabs to display all the WO information.

<Frame>
  ![Image](/images/LL-151.png)
</Frame>

1. WO severity: Emergency, Urgent, Normal or Resident Responsible.
2. Click this allows you to modify the WO severity:

<Frame>
  ![Image](/images/LL-152.png)
</Frame>

2. Initials of the people viewing the WO.
3. WO Title
4. WO Number
5. Navigation tabs

### “Action” dropdown menu

The “Action” menu is one of the main options on the WO page that will allow you to:

<Frame>
  ![Image](/images/LL-153.png)
</Frame>

- Create notes
- Create tasks
- Update the WO status
- Change the WO severity

### Task(s) Notification

The task(s) bubble notification will show you how many tasks there are open in a WO. When you click the bubble, it’ll be expanded to show more information about the tasks.

<Frame>
  ![Image](/images/LL-154.png)
</Frame>

Collapsed notification

<Frame>
  ![Image](/images/LL-155.png)
</Frame>

The expanded notification will show additional task(s) details and options:

1. Task for Latchel
2. Task for PM
3. Hide button to collapse the notification

### Details

The details tab contains information about different components of the WO and each of the sections can be expanded and collapsed. See below for additional details on each one.

<Frame>
  ![Image](/images/LL-156.png)
</Frame>

#### Current State

<Frame>
  ![Image](/images/LL-157.png)
</Frame>

This section shows the WO status.

#### Problem and Location

<Frame>
  ![Image](/images/LL-158.png)
</Frame>

This section shows the type of problem reported in the WO and the location where it is occurring.

#### Skill

<Frame>
  ![Image](/images/LL-159.png)
</Frame>

The skill represents the type of Service Provider who’s dispatched for this WO and the required skill.

#### Property

<Frame>
  ![Image](/images/LL-160.png)
</Frame>

1. Property address where the issue is occurring
2. Local property time
3. Weather information for today and tomorrow
4. Number of currently open WOs
5. Number of recently closed WOs

#### Service Provider

<Frame>
  ![Image](/images/LL-161.png)
</Frame>

This section shows information about the Service Provider assigned to the WO (if any).

1. SP’s information.
2. Ellipsis button to assign or remove an SP.
3. SP instructions about the WO.
4. Auto-Assign toggle to trigger the system’s automation to find an SP (usually not modified by agents)

#### Emergency Contacts

<Frame>
  ![Image](/images/LL-162.png)
</Frame>

Emergency contacts is where you can find the contact information of the people from the PM company who can be contacted in the case of an escalation.

1. Contact information.
2. Escalation email when the escalating to the contacts failed.

#### Warranty

<Frame>
  ![Image](/images/LL-163.png)
</Frame>

This is where warranty information about the property will be stored.

#### Resident

<Frame>
  ![Image](/images/LL-164.png)
</Frame>

This is where you can see the resident’s information:

1. Name
2. Phone number
3. Email
4. Dial button to call the resident

#### Property Access

<Frame>
  ![Image](/images/LL-165.png)
</Frame>

This section shows whether or not there’s permission to enter the property without the resident being present.

1. Toggle for permission to enter.
2. Instructions for how to be able to access the property.

#### Additional Information

<Frame>
  ![Image](/images/LL-166.png)
</Frame>

1. Who created the WO, timestamp, and source of creation.
2. The resident’s link to view the WO.
3. Whether or not the resident has the capability to cancel the WO (agents don’t modify this option).

#### Subscriptions

<Frame>
  ![Image](/images/LL-167.png)
</Frame>

This section shows the current Latchel subscription applicable to this property.

#### Property Manager

<Frame>
  ![Image](/images/LL-168.png)
</Frame>

This section shows who’s the property manager for this property.

### Activity

<Frame>
  ![Image](/images/LL-169.png)
</Frame>

The activity tab contains a mix of user-created logs and system-created logs. The data in this history allows users to understand the life of the work order in order to proceed with it.

1. Allows you to cycle the history view between the following: All activity, Tasks only, Automated Emails only, Automated SMS only, Calls only, Notes only, and Sort by newest or oldest
2. Sort by newest or oldest
3. Download the WO history.

#### Tasks

The Tasks view has a couple of additional options from the other views.

<Frame>
  ![Image](/images/LL-170.png)
</Frame>

1. Dropdown menu to view Open, Closed, or All Tasks.
2. Edit button on the task where the different fields of the task can be edited.

### Critical Notes

<Frame>
  ![Image](/images/LL-171.png)
</Frame>

This section can contain notes that are very relevant to the WO. Since the information they can contain is so varied, the usage will change on a case-by-case basis. There are three types of notes available in this section (if applicable):

1. Property Manager Notes
2. Property Notes
3. Service Provider Notes

### Summary

<Frame>
  ![Image](/images/LL-172.png)
</Frame>

This shows a summary of the diagnostic sequence that was followed during creation and any additional details that were entered.

### Budget

It shows information about the budget limits the PM has defined to control costs derived from the work performed in the WOs.

<Frame>
  ![Image](/images/LL-173.png)
</Frame>

1. The “Approved Budget” is the only one a Service Provider can see and is authorized for.
2. The “Hard Budget Limit” is an amount only Latchel can see and serves as a reference for Latchel to approve estimates up to this amount without involving the PM.

### Invoices

This section shows information about invoices created using the Latchel system.

<Frame>
  ![Image](/images/LL-174.png)
</Frame>

1. This option is used to create invoices.
2. Clicking on the invoice number will display all invoice details.

### Files

This tab contains all files that have been attached to the WO, for example, before/after photos, estimates, etc.

<Frame>
  ![Image](/images/LL-175.png)
</Frame>

1. Button to add files
2. Clickable file name which displays the file
3. Dropdown menu to classify the file
4. Download button
5. Delete button

### Reviews

Once a WO has been completed, the Resident has the ability of rating their experience with the WO and this section will show this rating.

<Frame>
  ![Image](/images/LL-176.png)
</Frame>

1. Rating for the Service Provider
2. Rating for the overall maintenance request
3. Optional comments left by the resident

### Special Note

This is an editable note meant to provide information for the entire WO. This was previously known as “summary” in the original WO design.
