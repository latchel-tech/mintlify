### Status Flow & State Diagram

<Info>
**What is in this?**
This describes all of the possible state changes and the logic behind these state changes. Any of the state changes in the flow can occur through the primary take action or expected exception paths. The “Other available state changes” can occur through secondary actions or rare edge cases.
