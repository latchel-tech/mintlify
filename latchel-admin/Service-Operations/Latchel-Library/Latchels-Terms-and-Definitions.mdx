#### Purpose

The purpose of this page is to provide an official reference of the terms used at Latchel with their definitions to reduce ambiguity when communicating internally and externally.

| **Recommendation** | **Definition** |
| --- | --- |
| **Service Provider (SP)** | A person or company performing the Work Order. |
| **Preferred Service Provider** | An external Service Provider onboarded to Latchel by the Property Manager. |
| **In-House Maintenance** | In-house maintenance resource working for the Property Manager to perform the Work Order. |
| **Latchel Contractor Network (LCN)** | Latchel’s network of sourced Service Providers. Property Managers can opt-in to this network in order to use Latchel’s Service Providers for their Work Orders. |
| **Latchel Vendor Network (LVN)** | TBD |
| **Latchel Service Provider** | A Service Provider who is part of the Latchel Contractor Network. These Service Providers are sourced by Latchel and can have two types of billing methods: Direct Deposit or Issued Cards. |
| **Resident** | Person occupying a property for living or commercial purposes. |
| **Home Assistant (HA)** | A resident amenity that includes financial protection for common resident-caused damages and coordinates home services like cleaning, lawn care, and more. |
| **Owner** | Person who holds title to and leases out a property. |
| **Property** | Real estate occupied by Residents. |
| **Latchel** | End-to-end platform that automates maintenance coordination and delivers best in class resident amenities. |
| **\[User\] Dashboard** For instance, we have multiple dashboards depending on user type: -Admin Dashboard -PM Dashboard -Resident Dashboard -Service Provider Dashboard | The different user experiences within Latchel (e.g. PM Dashboard, Resident Dashboard). |
| **Work Order (WO)** | Maintenance and home services requests submitted to Latchel. |
| **Sourcing** | Service provider sourcing involves identifying and recruiting suitable vendors to handle the job at hand. The process includes several key steps, such as proactively searching for providers with high ratings on platforms like Thumbtack or Home Advisor, or cold calling providers found through Google. Onboarding them ensures they are properly set up with the necessary contact information. Additionally, new providers should be informed about supported payment methods, scheduling capabilities on the platform, and the necessity to confirm budget limits while formally communicating any increases before commencing work. |
