## Objective

<Info>
Users will be able to use the pre-determined "Quick Create tool"  to create a new Service Provider with pre-selected skill sets generally performed by a handyman and general contractor
</Info>

<Info>
Handyman and general contractors can perform work across several skill categories.
Quick create allows you to create a new Service Provider with pre-selected skill sets generally performed by a handyman and general contractor.
</Info>

### Step-by-Step Guide
**Process Overview**

#### Step 1: Create a New Service Provider that is a Handyman or a General Contractor
1. Begin by adding a new Service Provider as usual.
  1. See: [↔ How To: Add a New Service Provider](https://latchel.atlassian.net/wiki/spaces/OPS/pages/794034545/How+To+Add+a+New+Service+Provider) 
<Frame>
  <img src="/images/LL-82.png" alt="Image" />
</Frame>

2. After completing Step 1 "Vendor Details" proceed to "Company Settings".
  1. Navigate to "Which skills does this vendor provide?".
  2. Indicate if this service provider is a new handyman or general contractor by adding "quick create skill set"
    1. Click "+ Add 'Quick Create' skill set" 
<Frame>
  <img src="/images/LL-83.png" alt="Image" />
</Frame>

    2. Now choose one of two categories 'Quick Create Skill' available.  
<Frame>
  <img src="/images/LL-84.png" alt="Image" />
</Frame>

      1. Handyman skills
      2. General Contractor skills
    3. The user has the option to Edit specific skill sets if needed.
      1. If yes, the user wants to Edit, click on the ellipses located to the right of the skill.  
<Frame>
  <img src="/images/LL-85.png" alt="Image" />
</Frame>

        1. The user may Update skills by adding or removing (de-select) skills as necessary by checking or unchecking skill category boxes as needed.
      2. If no, the user is choosing to use the original Quick Create skill set defaults.
    4. Click Save.
      1. The new Handyman or General Contractor is now created.
    5. After creation, the user will be automatically directed to the new service profile.
3. For each Service Provider, you can edit the skill category and skill sets in case a specific service provider does not perform a skill that was applied with quick create:
  1. [↔ How to: Add or Remove Service Provider Skills](https://latchel.atlassian.net/wiki/spaces/OM/pages/791281864/TECH+101+How+to+Add+or+Remove+Service+Provider+Skills)
