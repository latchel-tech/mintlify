## Objective

<Info>
Property Managers are able to prioritize which Preferred Service Providers they want to use in their account and the order of priority they should be used, i.e. the Property Manager can determine which Service Provider should be selected first for each skill category. When a new Preferred Service Provider is created, it has to be added to the Property Manager priority list so they can be assigned to work orders. If they are not in the priority list, they will not show up in the list of Service Providers available for a certain skill in the Service Provider assignment tool. In addition to adding the Preferred Service Provider to that priority list, all the relevant skills also need to be selected.
</Info>

<Info>
Prior to this process, a new Service Provider was created or we have updated a Service Provider Profile to add or remove skills ([↔ How to: Add or Remove Service Provider Skills](/wiki/pages/createpage.action?spaceKey=OM&title=%E2%86%94%20How%20to%3A%20Add%20or%20Remove%20Service%20Provider%20Skills))
</Info>

#### **Add the New Service Provider to the Property Manager Priority List (or Remove from the List)**

<Warning>
**Preferred Service Providers will need to be prioritized in order to be available for assignment, i.e. they will need to be added to the Property Manager Priority List.**
**If the Property Manager has not define which Service Provider should be prioritized, set any handyman as priority 1, and others following it.**
</Warning>
1. If there are vendors available to be added to a certain category, you will see the "+ include vendor" button. You will click on it to add a new Service Provider to this category.
  1. 
<Frame>
  <img src="/images/LL-118.png" alt="Image" />
</Frame>

2. The list of other Service Providers that have this category will appear and you will click on "+include" to add them to the priority list.
  1. **Note** that if you created a brand new Service Provider that has multiple Skill Categories, you will need to add the new Service Provider for each category one by one.
  2. 
<Frame>
  <img src="/images/LL-119.png" alt="Image" />
</Frame>

3. Once you click on the Service Provider you want to add to the Priority list, you will be prompted to select the skills that you want to be included. Again, some Property Managers may prefer to limit the skills they want a certain Service Provider to work on their accounts. Select the skills you want to be available for this Property Manager and "save"
  1. 
<Frame>
  <img src="/images/LL-120.png" alt="Image" />
</Frame>

4. The new Service Providers will be added to the bottom of the priority list. To modify the priority list, see [step5](#id-(PREMIUM)Howto:AddorRemoveServiceProvidersandSkillsfromaPropertyManagementPriorityList-step5)
  1. 
<Frame>
  <img src="/images/LL-121.png" alt="Image" />
</Frame>

5. To remove a Service Provider from the Priority List, click on the three dots on the right side of the Service Provider section that you want to remove. Click on "Remove from priority list"
  1. 
<Frame>
  <img src="/images/LL-122.png" alt="Image" />
</Frame>


#### **Edit Priority List and Sequence**
1. For each Skill Category, you or the Property Manager can edit the sequence the Service Providers should be used. To do that, click on "Edit Priorities"
  1. 
<Frame>
  <img src="/images/LL-123.png" alt="Image" />
</Frame>

  2. A new six dot icon will appear next to the priority number. Click on it and hold to select the Service Provider. Drag it up or down to change their priority. When you finish reorganizing the priority list, click on "Done Updating Priorities"  to save your changes
  3. 
<Frame>
  <img src="/images/LL-124.png" alt="Image" />
</Frame>


#### **Edit Service Provider Skills Used by a Certain Property Manager**
1. Click on the three dots on the right side of the Service Provider section that you want to edit.
  1. 
<Frame>
  <img src="/images/LL-125.png" alt="Image" />
</Frame>

2. You will get the option to either "Edit their Skills" or to "Remove this Service Provider from the Priority list"
  1. 
<Frame>
  <img src="/images/LL-122.None" alt="Image" />
</Frame>

3. Click on "Edit Skills" and you will see a list of skills this Service Provider has in their profile. You can check or uncheck skills.
  1. Checking or Unchecking skills will NOT change the Service Provider skills in their profile. It will only add or remove skills that the Property Manager wants or not to use in their account.
  2. Click on "Save" to enter your skill selection
  3. 
<Frame>
  <img src="/images/LL-126.png" alt="Image" />
</Frame>
