## Objective

<Info>
Each work order will be request to resolve a maintenance issue and that issue will require a Service Provider with a certain skill. Therefore, skills are defined as the work that needs to be done to resolve an issue. When a work order is created via the Latchel console, the agent will assess the request and define what is the work that needs to be done and apply the appropriate skill. The skill selected will be used as a way to filter through all Service Providers in our system and list the ones that have that skill and will be able to resolve the work order.
</Info>

#### **Add or Edit a Skill in a Work Order**
1. When the work order is created via the Latchel Console, the agent will be required to select a skill.
2. When you open the work order, check the job title and description and check if the skills selected are appropriate. If there is no skill selected (screenshot below), you will need to select those prior to assigning a vendor.To add the skill, click on the work order, click on (None)
