<Note>
  The purpose of this SOP is to provide a step-by-step guide on how to access the Latchel cloud device to troubleshoot a client's AppFolio sync.
</Note>

## Overview

<Tip>
  **TIP:** To identify the last sync date, open the [**Integration Health Metrics**](https://docs.google.com/spreadsheets/d/1lqN_yI3vZUehb9BZylCvXK0KU-PFfpJCkDvw1_sgWug/edit?gid=186001220#gid=186001220) dashboard, go to the **PM Metrics** tab, and filter column **Q — Is the integration run by Latchel?** to show only rows marked **Yes**. Then check column **AS — Last sync date**. **If you don’t have editor access, you can review the [Latchel Internal Sync PMs list](https://docs.google.com/spreadsheets/d/1FZQ_gcofCAjOcqk4Sb9_lIKlRK_3zUIEAUon-PA40q0/edit?gid=0#gid=0) and compare it with the Integration Health Metrics Dashboard** (_You can use CTRL + F to search for each PM_).
</Tip>

<Tip>
  **Monitor the internal Latchel syncs daily.** The PM Metrics query runs every hour. If you notice a PM whose date isn’t updated to today’s date in the **Last sync** column, you will need to troubleshoot the sync. **It’s best to troubleshoot the sync before the alerts are triggered in the #integration-sync-issues-internal channel**.
</Tip>

## Step by step

### **Step 1: Review and Acknowledge Integration Alerts**

a. If, for any reason, an alert notification for the following triggers in [#integration-sync-issues-internal](https://latchel.slack.com/archives/C096E7A625U) (\_The script for these alerts runs every day between 9–10 a.m. and 9–10 p.m. CST):

- Integration hasn’t run in 2 days
- Integration hasn’t run in 4 days

you will need to acknowledge the notification and proceed to step 2. **If this is not the case, please skip step 1 and proceed to step 2 if necessary.**

<Frame>
  ![image-20251216-204807.png](/images/Intg-72.png)
</Frame>

<Note>
  Other notifications, such as:

  - Integration hasn’t run in +4 days
  - Data Sync Error: Properties, Tenant, Work Orders
  - Latchel Sync Request

  **are currently handled by Trisha. In the future, these will also be monitored by other team members.**
</Note>

### Step 2: Log in to the Remote Server Cloud

a. Log in to the designated **Latchel cloud account** where syncs are managed. Log in using the credentials provided

### **Step 3: Connect to the TeamViewer Virtual Desktop**

a. Once logged in, go to **Devices** and click **Connect**.

<Frame>
  ![image-20260603-212718.png](/images/Intg-73.png)
</Frame>

### **Step 4: Troubleshoot the Sync in the PM's Profile**

a. A virtual desktop will load. **Open the Chrome browser if the PMs tab isn’t already open.**

<Frame>
  ![image-20260603-212956.png](/images/Intg-74.png)
</Frame>

b. **Select the specific PM profile** you need to check and identify the issue:

<Tip>
  **NOTE:** Each PM has their own Chrome profile. Keep them as they are so the sync runs smoothly. Open the corresponding client Chrome profile to troubleshoot the issue.
</Tip>

1. **If the Chrome page is not responding**, refresh it and then **continue to option #2**.
2. **If the PM’s last sync is behind the current date**, click the floating **Latchel** button on the right sidebar. From the options that appear, select **Sync data in both directions (Slower) and click on Start sync**. This will sync residents, properties, and work orders (for some PMs, depending on their subscription). Owners may appear as well since they are also being synced; however, this is being implemented gradually by Engineering.

<Frame>
  ![image-20251030-192005.png](/images/Intg-75.png)
</Frame>

3. To confirm the sync was completed successfully, go to Latchel and open the PM’s profile.
4. Then, go to the Integrations dashboard and, **check the Last sync column**. **The date should be updated to today’s date**.
   ![Image](/images/image-142.png "Image")

<Warning>
  The last import (column J) for **owners, property, tenant** and **work orders (jobs)** doesn’t always run daily, as it depends on whether the PM has new information to sync and on the subscription type. Also, _owner importing is being enabled gradually by the Engineering team._
</Warning>

<Tip>
  If, for any reason, the sync doesn’t go through, review whether the PM removed report access. You can check the following [job aid](https://help.latchel.com/how-to-grant-report-permissions-to-latchel-in-appfolio) to learn which reports are required for the sync. 
</Tip>

### **Step 6: Keep the Session Active.**

a. After troubleshooting, **ensure ALL the client’s Chrome profile tabs remain open** in the virtual desktop. This allows the syncs to continue running automatically.

### **Step 7: Close the Connection Correctly**

a. Close the remote server cloud tab **from the TeamViewer virtual desktop**.

<Frame>
  ![image-20260603-213320.png](/images/Intg-78.png)
</Frame>

<Warning>
  Never select the icon shown below that looks like a computer with an “X” inside it, as this will disconnect the session from the remote server.
</Warning>

![Image](/images/image-145.png "Image")

### **Step 8:** If the sync alert was triggered (Step 1), follow this final step

a. Once you have completed all steps, you can mark the notification with a “done” emoji.
