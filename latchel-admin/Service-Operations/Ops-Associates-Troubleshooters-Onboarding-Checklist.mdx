## Purpose

To provide a checklist for the onboarding process when a new virtual assistant is hired.

| **Item** | Notes |
| --- | --- |
| Offer Letter | • Create the offer letter in Word Doc using one of the templates<br />• Upload the document in [Hellosign](https://app.hellosign.com/home/manage) and complete signature for Will<br />• Send to the employee for signature<br />• When you recieve the completed document send it to the employee with their welcome email for their records. |
| Latchel email account | • Go to [Google Admin Console](https://admin.google.com/ac/users) and login<br />• Click Users> add new user<br />• Enter in their information<br />• Enter in Generic password<br />• send the login information to them and a copy to yourself |
| Slack | • Open the [Slack](https://app.slack.com/) app<br />• Click the Latchel dropdown and select invite people<br />• Enter in their name and Latchel email address<br />• Invite them the the corporate channels and any channels specific to their role. (Random, General, Core group, Latchel Competitions, Tech escalationsn & Customer love, adventure, music, super hero academy, market watch, words are hard)<br />• Invite them to ops channels (operations, time_off_requests, shift_support_escalations, on_demand_escalations - if ops troubleshooter, ask-answer, reimbursements, suggestions) |
| Atlassian | • Login to [Confluence](https://latchel.atlassian.net/wiki/discover/all-updates)<br />• Click the settings icon in the bottom left hand corner<br />• Click administration > invite user<br />• Eneter their Latchel email<br />• Select basic user from the role drop down<br />• Select Jira and Confluence |

## Action Items

- [ ] Create an offer letter
- [ ] Request personal information from their manager or their resume ( Address, phone number, Date of birth)
- [ ] Create a Latchel email account
- [ ] Send a Slack invite
- [ ] Invite them to Jira and Confluence
- [ ] Make them a user in Stage with the approprite role
- [ ] Create a Zendesk account
- [ ] Create a PagerDuty account
- [ ] Enroll them in Co-Assemble, add to the appropriate group and enroll in corresponding onboarding courses.
- [ ] Add them to the All Hands and Ops All Hands weekly meetings
- [ ] Schedule 1:1s with leadership ( Will, Ethan, Joseph, Jennifer F. & Jorge)
- [ ] Communicate with Joseph when all action items have been completed
- [ ] Add to all the appropriate user groups
- [ ] Create an account in letsdeel.com

**If in the States and not from Rocket Station**

- [ ] Go through the new hire process in TriNet.
- [ ] Request copies of the apropriate identification
- [ ] Complete I-9 within the first 3 days of hire.
