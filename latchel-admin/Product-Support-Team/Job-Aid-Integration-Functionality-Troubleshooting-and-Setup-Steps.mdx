<Note>
  This job aid outlines the steps for setting up, managing, and troubleshooting the integrations between Appfolio, Yardi, Propertyware, and Rent Manager. It ensures consistency in how these integrations are handled across different teams and projects.

  Applies to all personnel involved in setting up and managing integrations across the various platforms. It covers:

  - Initial setup of new connections
  - Monitoring and maintaining integration functionality
  - Troubleshooting common issues
</Note>

### **2. Setup of New Connections**

<Warning>
  If the customer already has resident and property data in Latchel, do not activate an integration without consulting with the data support team. Escalate the ASM Ticket via Assembly into the Data Support Team space and share “**Data Migration**” as the task type. Do not proceed with the set up steps below. Data Support will manage this transition and keep you updated in the slack thread.
</Warning>

### **4. Escalation Process**

1. If there is an unexpected outcome with existing functionality

- **If the user is utilizing the Latchel Chrome Plugin (Appfolio)**, instruct the user to follow these steps: [https://help.latchel.com/s/article/How-to-Report-Bugs-and-Issues-with-our-Tools](https://help.latchel.com/s/article/How-to-Report-Bugs-and-Issues-with-our-Tools). The debug report is required for engineering to troubleshoot further.
- **For all other integrations,** continue to post the escalation in the `#bug-report` channel in slack using the “Bug Report” workflow.
  - At that point, you may be instructed to post the issue in the `#tech-high-sev-escalations` channel. Approval is required before escalating to this channel.

2. If there is a request to add NEW functionality to an existing integration
3. Fill out the workflow “Feature Request” workflow in the `#feature-requests` channel.
